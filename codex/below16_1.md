## Setting

N = pq, primes p < q <= 2p, n = log2 N, P = sqrt(N). Deterministic factoring by one-sided exponent collisions in (Z/N)^* (Lehman / Harvey 2021 / Harvey-Hittmeir 2022 line). A *target* is an integer-valued Laurent polynomial g(p) (q = N/p) of bounded degree, e.g. the HH class lock: for a modulus M with gcd(M, ABN) = 1 and a root r of B r^2 == A N (mod M), every p == r (mod M) has B p + A q == c (mod M^2) with c computable from N, so g = (Bp + Aq - c)/M^2 is an integer in a window [U, U+W). Since B + AN - (Bp + Aq) = (p-1)(Aq - B), beta^{B+AN-c} == beta^{M^2 g} (mod p), so a shared baby list gamma^i (gamma = beta^{prod M^2}) and giants per target detect g by a gcd/product tree. Cost model: X >= #targets and sum_tau W_tau <= X^2 (shared list of length m: m + sum ceil(W/m)).

**Theorem A (multimod, proved, model M+):** any family of bounded-degree targets with ANY moduli/classes (one per target), interval windows, one base, sumset BSGS cost, that covers EVERY integer candidate p in [sqrt(N/2), sqrt N] for a fixed N, has X >= c N^{1/6}. Per-target coverage: a degree-1 two-term target with height H (H := max(|A|,|B|) over denominator M^2) covers <= C (P W / H)^{1/2} + C candidates (M cancels); degree e >= 2 targets cover <= C P^{1-e/K} W^{1/K} + C, so they alone need N^{1/5} (Thm A'). Cauchy-Schwarz then gives P <= C P^{1/2} X^{3/2}.

**Theorem D' (dcltheorem, proved):** DCL (all primes ell near N^{1/6}H^{-1/3}, small fixed weights (A,B) <= H, N-determined roots, whole-range windows W ~ H sqrt(N)/ell^2) factors all but O(N^{-eps}) of balanced semiprimes deterministically in N^{1/6+5eps/6} polylog. So 1/6 is attained on average; Thm A is a FULL-CANDIDATE covering bound for fixed N, not an average-case bound.
