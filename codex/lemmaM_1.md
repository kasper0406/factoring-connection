## Background (established in this project; you may rely on it)
- Lee–Venkatesan (LV), "Rigorous analysis of a randomised number field sieve", J. Number Theory 187 (2018) 92–159, arXiv:1805.08873. They prove: for every n, expected time L_n[1/3,(64/9)^{1/3}+o(1)] to produce x² ≡ y² (mod n). Randomness: m uniform near L(2/3, 1/δ); f = f̂_{n,m} + (x − m y)R(x,y), R with i.i.d. uniform coefficients of size L(2/3, κ−1/δ); pairs (a,b) uniform in a box; HECM smoothness tests; quadratic characters at large random primes; stochastic deepening; uniform kernel sampling. Non-triviality x ≢ ±y is conditional (their Conj. 7.1, Blum n only).
- Rigorous record otherwise: Lenstra–Pomerance JAMS 1992, L[1/2, 1+o(1)] (class groups). Pomerance 1987 / Dixon: L[1/2, √2]; Vallée: L[1/2, √(4/3)].
- **Lemma H (proved).** For every odd composite n, fruitfulness Φ(S) = [u(S)/φ(v(S))] ∈ μ₂(Z/n)/{±1} is a group homomorphism on the space K0 of true square dependencies.
- **Bockstein formula (proved).** Φ(S) = Σ_{i∈S} β_i on K0 for an explicit per-relation bit β, which is half of a 2-power-order character ψ = χ_pχ_q that vanishes mod 2^c on every relation. For Blum n and QS: β(x) = [J_n(x) = −1] (+ a 2-adic term). For Blum n, degree-1 NFS with forms L1, L2 (Res = ±n, |S| even imposed): β = ⌊Ω_T(L1L2)/2⌋ mod 2, T = {ℓ : (ℓ/n) = −1}.
- **Prop R (proved).** With x the exact square-class vector of a relation (C coordinates, including the |S|-parity column), and δ_w = Pr[β ≠ ⟨w,x⟩] under the kept law, a batch of M i.i.d. kept relations has Pr(Φ ≡ 0 on the batch kernel) ≤ Σ_w (1−δ_w)^M ≤ 2^C(1−δ)^M, δ = min_w δ_w.
- Hierarchy: Conjecture F (batch-level, Pr[Φ ≢ 0] ≥ L^{−o(1)} under LV's search law) ⇐ Lemma M (δ ≥ L[1/3,−o(1)] on an L^{−o(1)} set of (m,f)) ⇐ an x-preserving, β-flipping, measure-preserving involution on a non-negligible part of the smooth set (Dixon's x ↦ εx is the model case).
- "Dixon in disguise": a degree-1 two-form sieve with hidden multiplier λ = r² (forms Gauss-reduced from the lattice c ≡ λd mod n) is provably fruitful but has coefficients ~√n, so cost L[1/2, √2]. A globally uniform hidden root has small ratio representatives c/d, |c|,|d| ≤ H, with probability ≤ 4H²·2^ω/φ(n). Appending a single uniform Dixon relation that is smooth over an L[1/3] factor base costs L[2/3].
- QS obstacle: even the w = 0 case of Lemma M for QS asks that J_n be non-constant on the smooth-weighted interval [√n, √n + L[1/2]], far below the Burgess range.

## Tasks

2. **Average over N.** Try to prove that, for almost all n in a natural family (ideally balanced semiprimes, or Blum semiprimes, in [X, 2X]), some randomized QS / degree-1 / LV-style NFS is fruitful with probability ≥ L^{−o(1)}. Look for a parametrization in which the n-dependence of the smoothness weights decouples from the character: e.g. LV's (m, f) with n = f(m), so averaging over n is averaging over free (m, f); or n = x² − s in QS; or n = det of the 2×2 coefficient matrix in degree 1. Quantify exactly what the quadratic (or classical) large sieve gives at the relevant lengths, and identify precisely where the argument fails. In particular, address the union over 2^C linear tests w in Prop R: can any averaging argument beat it, given that the LV parameter space has only n^{O(1)} points while C = L[1/3]?
3. **β-flipping involutions.** Search systematically for smoothness-preserving maps on relation sets that keep the square-class vector and flip β: Galois automorphisms of K; several polynomials sharing the root m (Coppersmith MNFS); twisting by units or S-units; two polynomial pairs sharing relations; GL2 actions on (a,b); conjugation in Q(√n) for QS. Prove that natural classes cannot work (a precise barrier), or exhibit one that does.
4. **Fruitfulness-free routes.** (a) Can LV-style rigorous relation generation be transplanted into a class-group / ambiguous-form computation (discriminant −kn) at L[1/2, c < 1] or better? What limits Lenstra–Pomerance to c = 1, and can modern smoothness inputs (Harper's smooth numbers in APs, Matomäki–Radziwiłł, Bombieri–Vinogradov for smooth numbers) lower it? (b) Hidden-root injection: any way to obtain Dixon-type relations r² ≡ (factor-base product) with r uniform in its fibre, at NFS-sized cost, so that fruitfulness follows from Dixon's symmetry rather than from Conjecture F? State the cost and exactly which steps are rigorous.
