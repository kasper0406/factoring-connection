# nfsfruit round 2: ADVERSARIAL review of claimed results on NFS fruitfulness

You are a hostile referee (analytic/algebraic number theory, factoring algorithms). For EACH numbered claim below decide: CORRECT / CORRECT WITH FIXES (give the fixes) / WRONG (give a counterexample or the broken step) / KNOWN (give the citation: is it folklore or published?). Check every quantifier, every sign / root-of-unity issue, well-definedness, and every cost claim. Then give an overall verdict and say which single claim is most likely to be wrong. You may run small exact computations in the current directory (python3 available) to test claims. Do not be polite; be precise.

Notation: n odd composite, coprime to everything relevant; K = Q(α), f monic irreducible of odd degree d, f(m) ≡ 0 (mod n), φ: Z[α] → Z/n, α ↦ m. Relations i: coprime pairs (a_i,b_i) with z_i = a_i − b_i m and a_i − b_i α both smooth. K0 = {S ⊆ relations: ∏_S z_i ∈ Q^{×2}, ∏_S (a_i − b_iα) ∈ K^{×2}} (an F₂-space). For S ∈ K0 let u = f'(m)√∏z_i ∈ Z and v = f'(α)√∏(a_i−b_iα) ∈ Z[α]; then u² ≡ φ(v)² (mod n). Fruitful ⟺ u ≢ ±φ(v).

**Claim 1 (Lemma H).** Φ(S) := [u/φ(v)] ∈ μ₂(Z/n)/{±1} ≅ F₂^{ω(n)−1} is a well-defined group homomorphism K0 → F₂^{ω−1}, for every odd n (no Blum condition). Hence uniform S ∈ K0 is fruitful with probability exactly 1 − 2^{−rank Φ}, and Lee–Venkatesan's Thm 2.3 (conditional on their Conj. 7.1) extends to every semiprime under the hypothesis Φ ≢ 0. (Their Remark 7.3 says for non-Blum n "it is unclear how (even notionally) one might show that the linear algebraic step may produce non-trivial congruences".)

**Claim 2 (Bockstein formula).** Let n = pq. For each of p, q choose a Dirichlet character χ_p of F_p^× of order 2^{v₂(p−1)} (so χ_p(−1) = −1), likewise χ_q; let c = max(v₂(p−1), v₂(q−1)), ζ a primitive 2^c-th root of unity. Define ψ on Z coprime to n by ψ(z) = χ_p(z)χ_q(z) and on K^× coprime to 𝔭𝔮 (𝔭 = (p, α−m), 𝔮 = (q, α−m)) by ψ(x) = χ_p(x mod 𝔭)χ_q(x mod 𝔮). Fix a Z-basis g_1..g_R of the S-unit group U_S of K modulo ±1 (S = factor-base prime ideals ∪ infinite places), write a_i − b_iα = ±∏ g_j^{c_ij}, z_i = ±∏ ℓ^{e_iℓ}, ψ(ℓ) = ζ^{τ_ℓ}, ψ(g_j) = ζ^{σ_j} with integer lifts τ, σ. Then t_i := Σ_ℓ τ_ℓ e_iℓ − Σ_j σ_j c_ij ≡ 0 (mod 2^c) for every relation, and for every S ∈ K0:
  Φ(S) = Σ_{i∈S} β_i (mod 2),  β_i := t_i / 2^c mod 2.
So Φ is the restriction to K0 of an explicit per-pair function β(a,b) (a "Bockstein" lift of the character ψ, which vanishes mod 2^c on every relation). β is well-defined modulo F₂-linear functions of the exact square-class vector x_i = (e_iℓ mod 2, c_ij mod 2, signs).
  Special cases (claimed; for Blum n, c = 1, ψ = Jacobi symbol J_n, everything computable from n alone):
  (2a) QS, relations x_i² − n = z_i: Φ(S) = Σ_{i∈S} ( [J_n(x_i) = −1] + [(2/n) = −1]·v₂(z_i)/2 ), because every odd factor-base prime ℓ | z_i has (n/ℓ) = 1 hence J_n(ℓ) = 1.
  (2b) Degree-1 NFS with forms L1 = c1x+c0y, L2 = d1x+d0y, common root m mod n, so d1 L1 ≡ c1 L2 (mod n), K0 requires |S| even: Φ(S) = Σ_{i∈S} ⌊t_i/2⌋ mod 2, t_i = Ω_T(L1(a_i,b_i)L2(a_i,b_i)) (with multiplicity), T = {ℓ ≤ B : J_n(ℓ) = −1}.
  Corollary (degeneracy): in (2b), if every relation has ⌊t_i/2⌋ even (e.g. all prime factors have J_n(ℓ) = +1), every congruence is trivial.
  (We verified (2a),(2b) exactly on every kernel basis vector of hundreds of toy instances.)

**Claim 3 (reduction to a static lemma).** In LV's algorithm, for fixed (m,f) the pairs (a,b) are sampled i.i.d. uniformly from the box and kept iff smooth, so the kept relations are i.i.d. uniform from the finite set X = X_{n,m,f}. Let C be the dimension of the exact square-class space (so K0 = {S : Σ_S x_i = 0}). Let δ = min_{w∈F₂^C} Pr_{(a,b)∼X}[β(a,b) ≠ ⟨w, x(a,b)⟩]. Then Φ ≡ 0 on K0 iff β ∈ span of the coordinate functions on the found relations, so
  Pr(Φ|K0 ≡ 0 | m,f) ≤ Σ_w (1−δ_w)^M ≤ 2^C (1−δ)^M.
Hence M ≥ (C ln 2 + ln(1/ε))/δ relations give fruitfulness failure ≤ ε, and the LV constant (64/9)^{1/3} is preserved provided **Lemma M** holds: with probability ≥ L_n[1/3, −o(1)] over LV's (m,f), δ(n,m,f) ≥ L_n[1/3,−o(1)]. A sufficient condition for Lemma M: a measure-preserving involution ι on a subset of X of relative mass ≥ δ' that preserves x and flips β (then δ_w ≥ δ'/2 for all w). Dixon's ε-multiplication is exactly such an involution on all of X; for QS/NFS none is known.

**Claim 4 (hidden-root multiplier; degree 1).** Pick r uniform in (Z/n)^×, λ = r² mod n. Gauss-reduce the lattice Λ_λ = {(c,d) ∈ Z²: c ≡ λd (mod n)} (det n) to e1 = (c1,d1), e2 = (c0',d0'); put (c0,d0) = e2 + t e1 (t small random). Set L1 = c1x + c0y, L2 = d1x + d0y (coefficients O(√n), Res = ±n). Then L1(a,b) ≡ λ L2(a,b) (mod n) for all (a,b). For S with ∏_S L1 = U², ∏_S L2 = W² (no parity condition on |S|), X = U, Y = r^{|S|}W satisfy X² ≡ Y². Everything except Y depends on λ only; conditional on λ (and all other coins) r is uniform on r·μ₂(Z/n). Hence for every output S of odd weight, Pr(fruitful | everything but r) = 1 − 2^{1−ω(n)} exactly (1/2 for semiprimes), with no conjecture. (Relation generation itself — smoothness of two random linear forms of size √n·box — is NOT claimed rigorous; existence of an odd-weight dependency is a parity-only condition.) This gives fruitfulness at the L[1/2] scale only.

**Claim 5 (barrier for hidden multipliers).** In any two-form sieve whose congruence is L1 ≡ λ·L2' (mod n) with λ the ratio of the forms' leading data, a uniformly distributed hidden root r (λ = r²) forces λ to take ≥ φ(n)/2^ω values, so the leading coefficients satisfy max(|c1|,|d1|) ≥ (φ(n)/2^{ω+2})^{1/2}; hence rational-side values ≥ n^{1/2−o(1)} and smoothness cost L[1/2] rather than L[1/3]. To keep NFS-sized coefficients (n^{o(1)}·L(2/3)) one would need a quasi-uniform sampler of r over the μ₂-invariant set {r : r² ≡ c/d, |c|,|d| ≤ L_n[2/3]} — no such sampler is known (a Vallée-type sampler reaches residues ~n^{2/3}).
