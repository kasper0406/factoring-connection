# detGRH pre-registration (agent `detGRH`, phase 13, 2026-10-20)

Frozen before any code for E1 exists and before any run. Deviations will be disclosed in
`notes/detGRH_results.md`. All arithmetic is exact. Toy sizes; these are correctness and illustration
checks of algebraic claims, not complexity evidence.

## Claims under test (stated before the runs; proofs go in the results note)

- **(MR) Multiplicative square roots.** For odd N, a group homomorphism y: (Z/N)^{×2} → (Z/N)^× with
  y(s)² = s exists iff every prime p | N has p ≡ 3 (mod 4). It is then unique: the principal root, i.e. the
  root that is itself a square. So the orchestrator's hypothesis "y multiplicative on the group generated by the
  seeds" (all of (Z/N)^× under GRH) can hold only for such N, and then χ(r) = y(r²)/r is the vector of Legendre
  symbols.
- **(FL) Full-lattice fruitfulness.** Γ = {±1} × Z^{π(B)} (rational factor base), ev: Γ → (Z/N)^×, Λ = ker ev.
  Then Φ_full: (Λ ∩ Γ²)/Λ² → (G_B ∩ μ₂)/{±1}, g² ↦ ev(g), is an isomorphism, G_B := ev(Γ). For a found sublattice
  Λ_c ⊆ Λ of full rank, put c := dim_F₂ Λ/(Λ_c + 2Λ) (the 2-rank of Λ/Λ_c). If c < dim (G_B ∩ μ₂)/{±1}, some
  dependency of Λ_c is fruitful.
- **(CY) Cocycle identity.** For any square-root function y computed from certificates, y(RR′)/(y(R)y(R′)) ∈ μ₂,
  and when it is ∉ {±1}, gcd(y(RR′) − y(R)y(R′), N) is a proper factor.
- **(Z) Z-rank route (Miller 1976 + Bach 1990, ERH).** If found kernel relations ∏_{q ∈ FB} q^{e_q} ≡ 1 (mod N)
  (−1 ∈ FB) have full Q-rank on FB, and FB contains every prime < 2 log² N, then any nonzero maximal minor D is a
  multiple of the exponent of G_B, and Miller's test with bases a < 2 log² N factors N. No F₂ fruitfulness is
  used.

## Experiment E1

**E1a (MR, exhaustive).** Every odd N with 3 ≤ N < 3000 and ω(N) ≥ 1. Harness (uses the factorisation): build
(Z/N)^× as a product of cyclic groups by CRT, count homomorphic sections of squaring on generators of the
squares (checking s(x)² = x for every square x by brute force), and check multiplicativity of the principal
root by brute force over all pairs of squares for N < 400.
- P-MR1: #sections = 1 if every p | N is ≡ 3 (mod 4), else 0. **0 violations.**
- P-MR2: for N < 400 with all p ≡ 3 (mod 4), the principal root is multiplicative on all pairs. **0 violations.**

**E1b–E1d instances.** Classes blum (p ≡ q ≡ 3 mod 4), mixed (p ≡ 1, q ≡ 3), both1 (p ≡ q ≡ 1 mod 4), tri
(three primes, any classes) × n ∈ {28, 32, 36} bits × 20 seeds = 240 instances, generated by
`src/detGRH/instances.py` (SHA-seeded, deterministic). Factor base FB = {−1} ∪ {primes ≤ B(n)} with
B(n) := the least power-of-two multiple of 64 that is ≥ 2 log² N, recorded per instance.

Operational relation sources (deterministic, see only N):
- F_lin: for k = 1, 2, …, K and x = 1, …, X (x ≤ B, so x is B-smooth), if x + kN is B-smooth, the kernel
  relation e(x) − e(x + kN).
- F_seed: r = ⌈√N⌉ + t, t = 0, …, T−1; if r and r² − N are both B-smooth, the square relation with known root r
  (and kernel relation 2e(r) − e(r² − N)).
- The relation (−1)² = 1, i.e. 2·e_{−1}.
Enumeration stops when the Q-rank of the kernel relations reaches |FB| plus 10 surplus relations, or at caps
(K, X, T) fixed in `experiments/configs/detGRH_e1.json` before the run.

**E1b (Z route; operational).** Compute a nonzero maximal minor D of the kernel relation matrix (exact), then
Miller's test with bases a < 2 log² N.
- P-Z1: in every instance whose kernel relations reach full Q-rank, Miller with some base a < 2 log² N returns a
  proper factor. **Frozen: 100%** (0 failures allowed). Diagnostic side check: the primes < 2 log² N generate
  (Z/N)^× (predicted 100%; if it fails for an instance, that instance is reported separately and P-Z1 is
  evaluated on the rest).
- P-Z2 (control): replacing every kernel relation v by 2v makes every F₂ dependency fruitless (100%) and the Z
  route still factors (100%).
- Descriptive (no frozen prediction): fraction of instances reaching full Q-rank within the caps; relations used.

**E1c (FL; diagnostic, uses the factorisation).** Compute Λ exactly from discrete logarithms modulo each p | N,
the 2-rank c of Λ/Λ_c for Λ_c = span of the found kernel relations, dim W := dim (G_B ∩ μ₂)/{±1}, and whether
a basis of the F₂ dependency space of Λ_c contains a fruitful vector.
- P-FL1: dim W = ω − 1 in every instance where G_B = (Z/N)^×. **0 violations.**
- P-FL2: c < dim W ⇒ fruitful. **0 violations.**
- Descriptive: the fruitful rate among instances with c ≥ dim W.

**E1d (orchestrator's multiplicativity test).** For the F_seed square relations (r_i, R_i = r_i² mod N), define
y(R) for any B-smooth residue class R ∈ [0, N) that is a square class of Λ_c by the canonical completion: the
unique combination λ of a fixed reduced-echelon F₂ basis of Λ_c with e(R) + λ ∈ 2Z^{FB}, y(R) := ev((e(R) + λ)/2).
For every pair i < j (cap 20 000 pairs per instance) with R_iR_j mod N B-smooth, compute the defect
δ_ij := y(R_iR_j)/(y(R_i)y(R_j)) and χ(r_i) := y(R_i)/r_i.
- P-CY1: δ_ij ∈ μ₂(Z/N) always, and δ_ij ∉ {±1} ⇒ gcd(y(R_iR_j) − y(R_i)y(R_j), N) is proper. **0 violations.**
- P-CY2 (the orchestrator's hypothesis predicts rate 0; the fair-coin heuristic predicts 1 − 2^{1−ω}): pooled
  over instances whose canonical completions exist, the fraction of pairs with δ_ij ∉ {±1} lies in
  [0.30, 0.70] for semiprimes and [0.55, 0.95] for tri. A rate of 0 in any class would support the hypothesis.
- P-CY3 (same heuristic): pooled fraction of seeds with χ(r_i) ∉ {±1} in the same windows.
