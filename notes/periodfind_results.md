Notation:
- N = pq is an odd balanced semiprime and G = (Z/N)^*. For a ∈ G, H = ⟨a⟩ and r = |H|.
- r_p = ord_p(a), r_q = ord_q(a), g = gcd(r_p, r_q), and i = [G:H] = φ(N)/r (for random a, i is small).
- e(x) = exp(2πix).
- For an observable g: G → C, set ĝ(χ) = E_{y∈G} g(y)χ̄(y), F_g(t) = g(a^t) and
  F̂(j) = E_{t∈Z/r} F_g(t)e(−jt/r).
- η_j is the character of H with η_j(a) = e(j/r). A "peak of order d" is a frequency j with r/gcd(j, r) = d.
- "Relative mass" means |F̂(j)|²/‖F‖², with ‖F‖² = E_t|F(t)|².

## 0. Verdict (plain language)

**No classical mechanism.** We found no cheap classical source of the period (one sample j/r, r itself, or a
multiple of λ(N)) from the Fourier side. For each class of observables we could analyse we can say precisely why.
Our results are obstructions for specified observable classes and access models. They are not a lower bound against
all classical Fourier strategies (codex adversarial round: "claim conditional obstructions"; accepted).

**The main question has an exact necessary condition** (Theorem T, §1.1). The Fourier peaks of F_g(t) = g(a^t) are the
multiplicative-character spectrum of g, pushed forward by restriction to ⟨a⟩.
- A heavy peak of order d exists only if g correlates with a multiplicative character of (Z/N)^* of order ≥ d.
  So "only characters concentrate" is an identity, as a necessary condition.
- It is not a converse: coefficients in a restriction class can cancel.
- Classical sparse Fourier learning (KM-type SFT over Z_Q: Mansour; GGIMS; AGS/Akavia; GMS) can find a sample j/r
  with polylog evaluations only if we can compute an observable that weakly correlates with a large-order character:
  a weak discrete-log-type predictor in (Z/N)^*.
- Conversely, a heavy peak exists when the class mass does not cancel (T3). One sample gives a divisor of r, which
  is useful once its order is ≥ r/poly.
- T is a standard pullback identity (folklore). The point is its use as the organising criterion.
- The closest prior formulation of our question is Akavia's "GP-access" model (thesis Ch. 5). There the learner sees
  f on a random geometric progression, and Akavia leaves its tractability open as a "win-win" for Diffie–Hellman
  hardcore bits.

**The classes we could analyse all fail, each for a precise reason:**
- **Additive-structure observables**: bits whose additive ℓ¹ size is poly(n) (MSB/interval, LSB, and their
  compositions with y², y⁻¹), e(by/N) (the Shor phase), low-degree polynomial phases, shifted Jacobi. They are
  provably flat (Prop W, KNOWN in substance: Korobov's bound). Every peak has |F̂(j)| ≤ (ℓ¹ size)·√N/r, i.e. absolute
  power ≈ i/r up to the ℓ¹ size, and the bound is nearly attained numerically. Middle bits have ℓ¹ size ≈ 2^{n/2},
  for which W is vacuous.
  - This is why Akavia's hidden-number-problem SFT does not transfer. Her oracle has exactly our shape,
    a ↦ MSB(s·g^a). She succeeds only because advice (discrete logs of a fixed query set) converts it to additive
    coordinates. She notes that without it access is DL-hard (KNOWN, Akavia CRYPTO 2009, p. 340; §1.3a).
- **CRT-local observables**: algebraic decision trees over Z/N with zero tests and leaf outputs, of any size,
  including coordinate-wise extension rings, tori, Lucas sequences and elliptic-curve formulas. Theorem GR-F (§1.3d,
  PROVED):
  - the power on frequencies outside (r/g)Z is ≤ 8·ε_split, where ε_split is the chance that a random orbit
    evaluation already splits N by a gcd;
  - the exempt "common-order" peaks have orders dividing g = gcd(r_p, r_q), a divisor of gcd(p − 1, q − 1), which is
    heuristically O(log N) on average;
  - for atypically large g (e.g. common-prime RSA), the theorem does not exclude the Fourier layer.
- **Characters computable from N alone:** we know only those generated by the Jacobi symbol (order 2).
  - Order-ℓ residue symbols become computable once one is given a nontrivial ideal factorisation of (N) in Z[ζ_ℓ].
    Such characters reveal only whether small primes divide r.
  - For Blum N, v₂(r) is exactly a quadratic-residuosity bit. For ℓ = 3 the per-a bit [3 | ord a] is a cubic-type
    residuosity bit, and only the λ-level bit [3 | λ(N)] is the QR bit "−3 is a square mod N" (§2). These are standard
    Φ-hiding-type assumptions.
  - This is a taxonomy, not a theorem (codex: the original "only Jacobi" claim was false as stated, since mod 35 an
    inflated cubic character exists once 7 is known).
- **Smoothness observables** (the non-generic, multiplicatively structured class used by index calculus):
  - Prop DB (PROVED) caps the relative peak at min(ρ/(1−ρ), (1−ρ)/ρ), with ρ the event density. It bites only for
    superpolynomially small ρ.
  - The data show genuine pretentious-character peaks: 9–253× the random baseline in E1 (B = 50), relative peak up to
    0.8–1.0·ρ for π(B) = 4. These peaks have **large order** (r/ord has median 1–3), so they carry real period
    information.
  - But coherence needs a factor base of ≲ n/log n primes, where ρ = N^{−1+O(1/log log N)}. With the inverse-
    polynomial ρ that SFT needs, the peaks fall to the random level (Prop SM, HEURISTIC; supported by the post-hoc
    scan). Our estimate is that "dual" (Fourier) index calculus costs N^{1−o(1)}.
  - Framing (an analogy, not a theorem): classical relation methods find vectors of the hidden relation lattice,
    while Shor samples its annihilator.

**"Building interference by evaluating at strategic x"** is a linear filter.
- A filter whose target coefficient strictly dominates against every phase pattern of a flat spectrum needs support
  exactly r (Prop UP, PROVED; strengthened from r/2 by codex).
- For the actual Shor-phase spectra, detecting the strongest peak from random samples needs m ≈ r–4r (E4,
  experimentally supported).
- Birthday collisions, a quadratic statistic, cost √r. Linear interference is the wrong tool unless g already
  concentrates.

**"A compressed representation in a multiplicatively adapted basis."**
- In the character basis, Shor's state is a superposition of r terms, each a product state in t. The x|y Schmidt
  rank is still r in every basis.
- The basis change has entries χ(y); evaluating faithful large-order characters exposes discrete logs.
- Prop BASIS (§1.4): any classical "measure y in basis B, then SFT" strategy needs branch functions that are
  Fourier-concentrated, which by Theorem T needs basis vectors correlated with large-order characters. It also needs
  efficient branch sampling and amplitude access.

**Barrier statement** (§6). This is a model theorem, not a factoring lower bound. Arbitrary efficiently computable g
outside these classes remain open, including high-degree algebraic preprocessing with an additive readout (O1).
- Building one with a 1/poly-heavy large-order peak would give classical order finding (Theorem T + Miller), hence
  factoring.
- The converse fails: easy factoring would not obviously supply such a g, which also needs discrete-log-type
  information.
- A barrier covering all of them would rule out efficiently computable weak predictors of large-order characters
  of (Z/N)^*. That would imply P ≠ NP, so it is out of reach (correctness critic: the first draft's "would prove
  factoring hard" was a logic slip).

**Subjective assessment.** Probability that this thread yields sub-L[1/3] factoring: < 1%.

## 1. Main question: which cheaply computable g concentrate F_g = g(a^x) on period peaks?

### 1.1 Theorem T (transfer identity). PROVED (elementary; a standard pullback identity on finite abelian groups, folklore)

For every g: G → C, every a ∈ G and every j ∈ Z/r:

  F̂(j) = Σ_{χ ∈ Ĝ : χ|_H = η_j} ĝ(χ).   (T)

*Proof.* Expand g = Σ_χ ĝ(χ)χ. Then F_g(t) = Σ_χ ĝ(χ)χ(a)^t, and χ(a) = e(j_χ/r) for a unique j_χ ∈ Z/r. Averaging
against e(−jt/r) over Z/r keeps exactly the χ with j_χ = j. ∎

Each restriction class {χ : χ|_H = η} is a coset of H^⊥ and has exactly i elements. Consequences:
- **(T1)** By Cauchy–Schwarz, |F̂(j)|² ≤ i·Σ_{χ|_H=η_j}|ĝ(χ)|².
  - The total mass on peaks of order ≥ d is at most i·(the ĝ-mass on characters of order ≥ d), because
    ord(χ) ≥ ord(χ|_H).
- **(T2)** A τ-heavy peak of order d (|F̂(j)|² ≥ τ, |g| ≤ 1) forces some χ whose order is a multiple of d, with
  |ĝ(χ)| ≥ √τ/i (triangle inequality over the i class members).
- **(T3)** Conversely, if |ĝ(χ₀)|² ≥ τ' and the other i − 1 members of χ₀'s class carry little mass, the peak at
  χ₀(a) has mass ≈ τ'.
  - Then SFT on F_g finds e(j/r) = χ₀(a) and hence ord(χ₀(a)), a divisor of r. Over random a this is a large
    divisor once ord χ₀ is large.
  - T is a necessary condition only. Coefficients within a class can cancel: if λ|_H = 1, then g = (χ − χλ)/2
    vanishes on H despite large character correlations (codex).
  - Also, ord(χ|_H) divides ord(χ).
- **(T4)** For g = χ a character, F_g = χ(a)^t is a pure tone: all its mass sits on one peak. Large-order χ would
  therefore be perfect observables (§1.2).
- **(T5)** For the comb g = [y = c] with c ∈ H, ĝ(χ) = χ̄(c)/φ for every χ. Every class sums to i·χ̄(c)/φ = η̄_j(c)/r,
  so every peak has relative mass exactly 1/r (codex blind §2, Construction A).
- **(T6)** On Z_Q with r ∤ Q, the windowed transform is Σ_j F̂(j)D_Q(j/r − k/Q), where D_Q is the Dirichlet
  kernel (codex). For Q ≥ N², long windows do not amplify small coefficients.

Verification: E1b, 216 checks on N ≤ 2000 with every character enumerated; max error 4·10⁻¹⁶.
Also `tests/test_periodfind.py::test_transfer_identity`.

So the main question is **exactly**: which cheaply computable g have ≥ 1/poly multiplicative-Fourier mass on a
single restriction class of large order? The rest of §1 goes through the candidate classes.

### 1.2 Characters computable from N alone (taxonomy, not a theorem)

"Computable" here means uniform polynomial time given only the unfactored N. With a factor in hand, every
small-order character is computable: e.g. mod 35, a cubic character inflated from mod 7 exists, and it is not
generated by the Jacobi symbol (codex counterexample to our first wording).

- **Jacobi** (y/N): F = (a/N)^t has only frequency 0 or r/2. It certifies 2 | r when (a/N) = −1. KNOWN, trivial.
- **Power-residue symbols.**
  - For ℓ odd and rational integers y coprime to ℓN, the ℓ-th power-residue symbol (y/(N))_ℓ in Q(ζ_ℓ) is 1. This is KNOWN:
    the symbols at the rational ideal (N) depend only on N mod the conductor (nonsmooth §5.4, abelian aggregate
    theorem).
  - Any other reciprocity-computable order-ℓ character of G needs an ideal 𝔞 ⊂ Z[ζ_ℓ] supported above N that is not
    (a power of) (N) itself. That is a nontrivial ideal factorisation of (N) in a cyclotomic ring.
    - The ideal of norm N exists only when p ≡ q ≡ 1 (mod ℓ). A principal generator also needs the relevant class
      to be trivial.
    - Ideals above only one of p, q are no easier to find than p itself.
    - For ℓ = 3 and norm N, the ideal yields a square root of −3 mod N.
    - We know no method to find any such ideal faster than factoring.
  - Even given the ideal, the character has order ℓ and costs poly(ℓ, n) to evaluate (e.g. Bach–Sandlund 2018 for
    cubic and quartic symbols).
- **Products of such symbols** have order dividing a product of small primes, so they are poly(n)-smooth.
  - They reveal at most whether each small ℓ divides r. That is p−1-method information without the smoothness
    hypothesis.
  - They never reveal a large prime factor of r.
- **No theorem.** Nothing proves that every efficiently computable character of G has smooth order. Such a theorem
  would imply hardness of DL-type problems.
- **Taxonomy of large-order computable characters** (not a theorem). The only constructions we know are:
  - Pohlig–Hellman decompositions: smooth order, and they need the factorisation and the group order;
  - formal-group / p-adic logarithms: Paillier's L on 1 + N·Z/N², Smart–Semaev–Satoh–Araki on anomalous curves.
    These live on kernel-of-reduction subgroups, reached only after annihilating the reduction.
  - These are exactly the two branches of Prop OA (nonsmooth §5.1): a smooth group order, or a {p, q}-group. The
    Fourier side meets the same dichotomy as the order-annihilation side.

### 1.3 The middle ground: non-generic, non-character observables

#### (a) Bit / MSB / interval functions, and why the HNP case differs

- **Prop W (additive-class flatness). KNOWN in substance** (literature critic).
  - For a single h this is Korobov's classical bound |Σ_{t<r} e(ha^t/N)e(bt/r)| ≤ √N for gcd(h, N) = 1, with the same
    orthogonality-plus-Gauss-sum proof. References: Korobov 1972; Konyagin–Shparlinski, *Character Sums with
    Exponential Functions and their Applications* (CUP 1999); Shparlinski 2003.
  - The ℓ¹ extension is routine. Codex blind §5 derived it independently.
  - **Statement.** Let g(y) = b₀ + Σ_{h∈G} b_h e(hy/N), with A = Σ_{h≠0}|b_h|. Then for j ≠ 0,
    |F̂(j)| ≤ A·√N/r.
  - **Proof.** Write Σ_{y∈H} e(hy/N)η̄(y) = (1/i)Σ_{χ|_H=η} Σ_{y∈G} e(hy/N)χ̄(y). Each complete sum is a Gauss sum
    mod N. By CRT it factors into prime-modulus Gauss sums of modulus √p or 1, so it is ≤ √N. Hence
    |F̂_h(j)| ≤ √N/r. Then use the triangle inequality over h. ∎ Reference: Montgomery–Vaughan, *Multiplicative
    Number Theory I*, §9.
- **The interval bit [y < N/2]** has A = O(log N). The nonunit h (multiples of p or q) contribute
  O(log N·(1/p + 1/q)), so |F̂(j)| = O(√N log N/r) (codex Construction D). The LSB and MSB of y, and of y² and y^{−1},
  behave the same way empirically (E1).
- **Absolute power.** ≤ A²N/r² ≈ A²·i²/N. Since r ≈ N/i, that is about A²·i/r: flat up to the index i and the ℓ¹
  size. For relative power divide by Var(F), which is ≈ 1 for ±1 or unimodular observables. The bound is informative
  only for r ≥ N^{1/2+δ}; for short orbits W says nothing.
- **Sharpness.** The bound √N/r for e(hy/N) is nearly attained by max_j (E1: ratio 0.99999 at n = 22 for small index i = 2, 4; 0.995 at n = 26, i ≥ 6). The
  Shor phase has no heavy peak at any frequency.
- **Polynomial phases** e(f(y)/N), f ∈ Z[y] of degree D < min(p, q), nonconstant mod p and mod q:
  |F̂(j)| ≤ D²√N/r. This follows from Weil's bound D√p for mixed sums at each prime (KNOWN: Weil; Castro–Moreno,
  Proc. AMS 128 (2000)). For rational f = u/v with deg u, deg v ≤ D, replace D² by (2D + 1)².
- **Huge-degree monomials** y^m reduce to the orbit of a^m (order r/gcd(m, r)). They are heavy only if that order is
  small, which is order annihilation (§1.3f).
- **Sparse polynomial phases** over subgroups are Bourgain-type sums. They have cancellation unless the exponent
  differences align with r, the analogue of slpcirc's Theorem SP. This is KNOWN for prime moduli (Bourgain 2005;
  Bourgain–Glibichuk–Konyagin 2006) and, under conditions, for composite moduli (Bourgain–Chang, GAFA 16 (2006);
  Bourgain, J. Anal. Math. 97 (2005)). The exact hypotheses for our N = pq setting were not checked here.
- **Why Akavia's HNP algorithm works and this does not. KNOWN** (Akavia, CRYPTO 2009, §1.2, p. 340, and §3.1).
  - Akavia's HNP oracle is indexed by the exponent: a ↦ P(s·g^a mod p), e.g. P = MSB. That is literally our shape
    F(t) = Ψ(s·g^t).
  - Her SFT (Thm 4, cost poly(log p, 1/τ, L1(f̂)) for f into the unit ball) runs on the additive function
    f_s(x) = P(sx). It needs f_s at a fixed universal query set S, and the advice Adv_{p,g} = {(x, DL_{p,g}(x)) : x ∈ S}
    converts the exponent oracle into those additive queries.
  - On f_s, the additive automorphism x ↦ sx moves P's O(log p) additive ℓ¹ mass to frequencies near s·k, so
    heavy coefficients exist.
  - Akavia states that without the advice "providing access to f_s is intractable (assuming computing discrete logs
    is intractable)".
  - In our language (Theorem T): queried in exponent coordinates, the observable must be concentrated in the dual of
    the multiplicative group. An additively concentrated P is multiplicatively flat (Prop W; Pólya–Vinogradov).
    Slogan, which is our phrasing of Akavia's point: **the observable must be concentrated in the dual of the group
    whose coordinates you can query.**
  - Related: Boneh–Venkatesan (CRYPTO 1996), the origin of HNP. González Vasco–Shparlinski 2001: HNP with
    multipliers from a subgroup, via Korobov/BGK sums, the closest additive-multiplicative precedent.
  - Akavia's thesis (MIT 2008) has two further relevant points.
    - Ch. 3: SFT over a finite abelian group needs its generators and their orders. For (Z/N)^* that description is
      the factorisation plus discrete logs, which is exactly the obstruction of Theorem T.
    - Ch. 5, the GP-access model: f is seen on a random geometric progression s, s^{k₁}, …. Thm 1.27: GP-LCN
      tractable ⇒ segment predicates are hardcore for DH. Its tractability is open. Our fixed-base F(t) = g(a^t) is a
      relative of GP-access, and our negative results are consistent with Akavia's "win-win" framing.

#### (b) The Shor phase e(b·a^x/N)

- This is Prop W with A = 1: |F̂(j)| ≤ √N/r for every j, and Σ_j|F̂(j)|² = 1 (Parseval). The spectrum is flat at the
  scale i/r: the max peak is 0.14–1.9·(ln r)/r in E1.
- This complements analytic §5: there, Weyl differencing leaves the phase invariant and the bit-cut rank equals the
  order. Here the Fourier spectrum on Z/r is flat. All three are views of one fact: the phase is a "Gauss period" of H.

#### (c) Mixtures of additive and multiplicative structure

- **Jacobi × additive**, g(y) = (y/N)e(hy/N): a twisted Gauss sum. The bound √N/r holds after shifting η by the
  Jacobi restriction. PROVED, same proof.
- **Shifted Jacobi**, ((y + c)/N), c ∈ G.
  - ĝ(χ) is a Jacobi sum J(χ̄, (·/N)) divided by φ. Per prime its modulus is √p, or 1 when χ_p is trivial or equals the
    Legendre character.
  - So |F̂(j)| ≤ √N/r for all j, with no exceptional frequency. PROVED. Test `test_shifted_jacobi_bound`; E1 ratio to
    the bound ≤ 1.001. The excess over 1 is only the normalisation by ‖F‖² < 1, since ((y+c)/N) = 0 at nonunits.
- **Jacobi × interval:** flat (E1).

#### (d) Extension rings and every CRT-local computation: Theorem GR-F. PROVED

**Model.** Ψ is computed from y ∈ G by an algebraic decision tree over Z/N:
- ring operations (in Z/N or any explicit finite free (Z/N)-algebra A in coordinates, e.g. (Z/N)[x]/(f), tori,
  Lucas sequences, projective elliptic-curve formulas);
- inversion of units allowed, with a non-invertible element counted as a split;
- constants from Z/N;
- branching on "v = 0" for computed v. For v ∈ A this means all coordinates are 0. A split means v ∈ pA \ qA or
  the reverse, and then gcd(N, a coordinate nonzero mod q) = p;
- any size and depth (exponentiations allowed);
- random coins either fixed, or drawn fresh per evaluation. In the latter case F = E_c F_c and, by convexity,
  Σ_vis|F̂|² ≤ E_c Σ_vis|F̂_c|² ≤ 8·E_c ε_c (correctness critic);
- output a function of the leaf with |Ψ| ≤ 1.
- The learner's adaptivity across queries does not matter, because the theorem concerns the spectrum of a fixed Ψ.

Let ε_split = Pr_{t∈Z/r}[some test on the run at a^t has v ≡ 0 at exactly one of p, q]. Each such test gives the
factor gcd(v, N).

**Theorem GR-F.** Σ_{j : (r/g) ∤ j} |F̂_Ψ(j)|² ≤ 8·ε_split. The remaining frequencies, the multiples of r/g, have
denominators dividing g = gcd(r_p, r_q), a divisor of gcd(p − 1, q − 1).

*Proof.*
1. Define the p-run as the same tree executed with arithmetic and zero tests mod p, and similarly the q-run.
2. If no test on the N-run at y splits, then at every node "v ≡ 0 mod N" ⟺ "v ≡ 0 mod p" ⟺ "v ≡ 0 mod q". By induction
   along the path, the N-run, p-run and q-run reach the same leaf.
3. Hence Ψ_N(a^t) = Ψ_p(a^t mod p) = Ψ_q(a^t mod q) off the split set S, which has density ε_split.
4. Write F = F_p + e_p, where F_p(t) = Ψ_p(a^t mod p) is r_p-periodic, e_p is supported on S and |e_p| ≤ 2, so
   ‖e_p‖² ≤ 4ε. Similarly F = F_q + e_q.
5. F̂_p is supported on (r/r_p)Z and F̂_q on (r/r_q)Z. Their intersection is lcm(r_q/g, r_p/g)Z = (r/g)Z, because
   gcd(r_p/g, r_q/g) = 1.
6. A frequency outside (r/g)Z lies outside (r/r_p)Z or outside (r/r_q)Z. There F̂ = ê_p or F̂ = ê_q respectively.
   Summing gives ≤ ‖e_p‖² + ‖e_q‖² ≤ 8ε. ∎

**Corollary.** Any heavy-hitter search on a CRT-local observable at absolute threshold τ > 8ε_split finds only
common-order frequencies, whose orders divide g. For a relative threshold, read τ·‖F‖² > 8ε_split.
- When g ≤ poly(n) (typical N), heavy peaks therefore reveal only small divisors of r.
- If ε_split = 0, nothing off (r/g)Z is visible at all.
- For large g (r_p = r_q gives (r/g)Z = Z; common-prime RSA has large gcd(p − 1, q − 1)) the theorem is vacuous, and
  the Fourier layer is not excluded.
- Evaluating Ψ at O(1/ε_split) independent random orbit points, monitoring the gcd of every tested value, already
  factors N.
- This is an available algorithm that makes the Fourier layer redundant for CRT-local Ψ up to polynomial factors. It
  is not a lower bound on every Fourier strategy (codex).

**The common-order exemption is real, not a technicality** (codex).
- N = 77, a = −1, with one test y − 1 = 0, gives F(t) = (−1)^t: a full-power order-2 peak with ε_split = 0.
- In general the exempt peaks have orders dividing g = gcd(r_p, r_q), a divisor of gcd(p − 1, q − 1). Over random
  primes, heuristically E[gcd(p − 1, q − 1)] ≈ Σ_{d} φ(d)·Pr[d | p−1]² = Σ_d 1/φ(d) ≍ log N. Pr[d | p−1] = 1/φ(d)
  is rigorous for small d (Siegel–Walfisz). So for typical N the exempt peaks reveal small divisors of r.
- The theorem says nothing to exclude them when gcd(p − 1, q − 1) is atypically large.

**Scope and status.**
- The CRT-run argument is the standard engine of generic-ring results: Aggarwal–Maurer, Eurocrypt 2009, "Breaking
  RSA generically is equivalent to factoring"; Jager–Schwenk, Asiacrypt 2009, where even the Jacobi symbol is
  generically equivalent to factoring.
- The Fourier packaging is a routine corollary of their simulation lemma; no Fourier statement was found by us or
  by the literature critic. Lineage: Boneh–Venkatesan EC'98 (SLPs); Damgård–Koprowski EC'02 (generic groups of
  hidden order); Maurer 2005; Leander–Rupp AC'06; Altmann–Jager–Rupp ICALP'08.
- Not covered: operations that use the integer representative (comparisons, bits, Jacobi, additive characters,
  smoothness). Those are classes (a)–(c) and (e).
- Outputs that decode a computed residue are not covered either. For N = 15, a = 2, Ψ(y) = e(y/15) has no tests, yet
  5/8 of its power lies outside the common frequencies (codex). The model is leaf-labelled outputs.
- Extension rings and curves need a CRT-compatible coordinate representation. Zero tests are coordinate tests, and a
  split is detected by coordinate gcds.
- Randomised trees: couple the random tape across the N-, p- and q-runs. The bound then holds for each tape, and by
  Jensen also for the averaged observable.
- E3 checks the inequality on 240 random trees: 0 violations.

#### (e) Integer-structure observables: smoothness. Prop DB (PROVED) + Prop SM (HEURISTIC)

The integer representative carries multiplicative information through its factorisation. Smoothness indicators
are the natural "multiplicatively structured but non-character" observables. They are what index calculus uses.

- **Prop DB (density bound, PROVED, trivial, KNOWN in substance).** If g = 1_E (centred), then for j ≠ 0,
  |F̂(j)|²/Var(F) ≤ min(ρ/(1 − ρ), (1 − ρ)/ρ), with ρ the orbit density of E.
  - *Proof.* |F̂(j)| ≤ min(ρ, 1 − ρ) (use E or its complement), and Var(F) = ρ(1 − ρ). ∎ (Symmetric form: codex.)
  - This excludes 1/poly-heavy peaks only for superpolynomially small ρ. Inverse-polynomially rare events still
    allow inverse-polynomial relative peaks.
- **Prop SM (pretentious characters; HEURISTIC + data).** Take g = [y ≤ N is B-smooth], with k = π(B). All "peak/ρ"
  numbers are relative power divided by ρ, consistent with DB.
  - **Existence (PROVED, Minkowski).** Some χ ≠ 1 has ‖arg χ(ℓ)/2π‖ ≤ φ^{−1/k} for all ℓ ≤ B.
    - If the map χ ↦ (arg χ(ℓ)/2π)_ℓ is injective, its image plus Z^k is a lattice of covolume 1/φ. The box
      [−φ^{−1/k}, φ^{−1/k}]^k has volume 2^k/φ, so Minkowski gives a nonzero point.
    - If the map is not injective, some χ ≠ 1 is trivial on all ℓ ≤ B.
    - Pigeonhole with M^k < φ boxes gives the weaker 2φ^{−1/k}. Our first draft's "φ boxes" version was off by one
      (correctness critic).
    - Pretentious characters: Granville–Soundararajan, JAMS 20 (2007). Under GRH the primes ≤ 2 log² N generate
      (Z/N)^* (Bach 1990), so exact triviality on a factor base that large is impossible.
    - This does not guarantee large order, a nontrivial restriction to H, or efficient construction (codex).
    - Empirically the peaks have large order: r/ord(η_j) has median 1–3, max ≤ 146, over E1 and the scan.
  - **Coherence.** If 2π·φ^{−1/k}·Ω(y) ≪ 1 on typical smooth orbit points (Ω(y) ≥ u = log N/log B), and the
    restriction to H is nontrivial, then |F̂(j)| ≳ ρ. The relative power is then ≈ ρ/(1 − ρ), saturating DB.
  - **Fixed B.**
    - k is fixed, so coherence improves as N grows, and the max peak tends to a constant fraction of ρ.
    - E1 (§7), B = 50: the max nontrivial peak is 9–222× the random baseline at n = 22 (median 37.7) and 36–253× at
      n = 26 (median 145). At n = 26 its ratio to ρ_H is 0.09–0.15.
    - The post-hoc scan (§7.5) gives peak/ρ ≈ 0.83–0.99 at π(B) = 4, rising with n.
  - **Trade-off estimate (HEURISTIC).** With exponents spread over k primes, the phase error of a box character on a
    smooth y is ≈ u·δ/√k, with δ = φ^{−1/k}.
    - Coherence needs 2^{n/k} ≳ u/√k, i.e. k ≲ n/log n. Then B ≈ k log k ≈ n and ρ = Ψ(N, B)/N = N^{−1+O(1/log log N)}.
      This uses de Bruijn's estimate for Ψ(x, (log x)^{O(1)}).
    - With an inverse-polynomial ρ (needed by SFT) one needs u ≲ log n/log log n, so k = 2^{Θ(n log log n/log n)} and
      δ ≈ 1. The pigeonhole guarantee is then ineffective. Under an equidistribution hypothesis for the vectors
      (χ(ℓ))_{ℓ≤B} as χ ranges over Ĝ (a precise conjecture would be needed; none is proved), no character is
      coherent and peaks return to the random level.
    - **Estimate:** the best smooth-observable relative peak is N^{−1+O(1/log log N)}. The o(1) decays slowly: the
      toy data at n = 24 reach ≈ 10⁻³ ≈ N^{−0.41} at π(B) = 8. So Fourier ("dual") index calculus costs N^{1−o(1)}
      evaluations, while primal index calculus (collect π(B) relations, then linear algebra) is L[1/2].
    - This is an estimate, not a theorem. An ineffective existence guarantee is not a nonexistence proof (codex).
  - **Analogy (folklore; Kitaev 1995; Childs–van Dam, RMP 82 (2010) §IV; used explicitly for hidden lattices by
    Eisenträger–Hallgren–Kitaev–Song, STOC 2014).** The relation lattice L = ker(Z^k → G) of the factor base has covolume |⟨ℓ ≤ B⟩|,
    which is φ when the factor base generates G.
    - Classical relation methods find vectors of L, which costs smoothness.
    - Shor's Fourier sampling yields annihilator (dual) information.
    - Classical dual sampling through smoothness would need characters ≈ 1 on all smooth numbers, which exist only for
      tiny k.
  - **Post-hoc scan over B (§7.5).** The peak-to-ρ ratio falls as π(B) grows: ≈ 0.9 (k = 4), ≈ 0.45 (k = 8),
    ≈ 0.09 (k = 15), ≈ 0.005 (k = 46), and the random level (2–4× baseline) for k ≥ 168, which is where ρ becomes
    large (0.2–0.7).
- **Rational reconstruction** (y ≡ u/v, |u|, |v| ≤ √N, then smoothness of u and v) is the L[1/2] refinement.
  Prop DB/SM apply to it unchanged (HEURISTIC).

#### (f) Order-annihilation observables

- **Formula (PROVED).** For g(y) = [y^M = 1], F = [d | t] with d = r/gcd(r, M). Every multiple of r/d carries
  relative mass exactly 1/d.
- **Reading.** Heavy iff d ≤ poly, i.e. iff M is a multiple of r up to a small cofactor. That is the
  p−1/ECM/torus regime of Prop OA, and the heavy frequencies reveal only d.
- **Pre-registration miss.** The E1 prediction "≤ 30 ln r/r otherwise" was mis-specified. For 100 < d < r/(30 ln r)
  the exact value 1/d exceeds it (§7).

### 1.4 Prop BASIS: compressed representations in other bases. PROVED (identities) + necessary condition

- **Setup.** Let |Φ⟩ = r^{−1/2}Σ_{t∈Z/r}|t⟩|a^t⟩ and let {β_k} be any orthonormal basis of functions on H. The basis may equally be taken on G, which matters if one
  wants it independent of a. Then
  |Φ⟩ = Σ_k √w_k|φ_k⟩|β_k⟩, with w_k = r^{−1}Σ_t|β_k(a^t)|² and φ_k = Σ_t conj(β_k(a^t))|t⟩/√(r·w_k).
  This is generally not a Schmidt decomposition.
- **Outcome distribution.** The reduced state of the t-register is I/r whatever basis is used for y. So QFT
  measurement gives j uniformly, independent of the basis.
- **Schmidt rank.** The t|y Schmidt rank is r, and local unitaries cannot change it.
- **The classical analogue.** Sample k ∝ w_k, then run SFT on φ_k. A necessary condition for success is that φ_k
  have a nontrivial τ-heavy peak of large order with substantial w-probability. By Theorem T this requires that the
  β_k correlate with large-order characters.
- **Not sufficient** (codex: the earlier "iff" was an overclaim). One also needs efficient sampling of k, amplitude
  access to φ_k, normalisation, and enough order information to recover r. T itself is one-way and admits
  cancellation.
- **The ideal basis** is the characters of H. There |Φ⟩ = r^{−1/2}Σ_j|tone_j⟩|η_j⟩, where each tone
  tone_j(t) = r^{−1/2}e(jt/r). On the qubit register x ∈ Z_{2^m} that Shor actually uses, the corresponding states
  are product (or near-product) states across the bits of x.
  - The superposition still has r terms and rank r.
  - The "compression" lies in the basis change, whose entries are η_j(y). Evaluating faithful large-order characters
    exposes discrete logarithms; low-order ones need not.
- **Comparison with MPS.** Analytic §5's "rank = order across bit cuts" rules out MPS in the computational basis. A
  classically evaluable change of basis on y helps only if its basis vectors correlate with large-order characters.
  That is the concentrating-g question again. Van den Nest 2011, Thm 2, requires a peaked spectrum of the classical
  postprocessing function, and Schwarz–Van den Nest 2013 require output sparsity; these are the matching
  hypotheses for their simulations. Bermejo-Vega–Lin–Van den Nest (arXiv:1409.4800) study normalizer circuits over
  black-box groups, which contain Shor; we did not check how their completeness result relates to BASIS.
  Composite-modulus DL implies factoring (Bach 1984), which is why faithful character bases are factoring-hard.

### 1.5 "Only part of the pattern": the cost of one peak. Prop UP (PROVED) + E4

- **Why one peak is enough.** One sample j/r suffices (it reveals r/gcd(j, r)). But to see it classically one must
  estimate F̂ at a useful k ≈ jQ/r.
- **Interference is a linear filter.** Any "interference built by evaluating F at strategic x" is a filter
  Σ_x w(x)F(x) = Σ_j ŵ(−j)F̂(j), with ŵ(k) = Σ_x w(x)e(−kx/r).
- **Prop UP (strict dominance needs full support).** Suppose the filter isolates the peak j₀ against every phase
  pattern of a flat spectrum, i.e. |ŵ(j₀)| > Σ_{j≠j₀}|ŵ(j)|. Then w(x) ≠ 0 for every x ∈ Z/r, so the support is
  m = r.
  - *Proof (codex).* If w(x*) = 0, Fourier inversion gives ŵ(j₀)e(j₀x*/r) = −Σ_{j≠j₀}ŵ(j)e(jx*/r), contradicting
    strict dominance. ∎
  - Our weaker first argument gave m > r/2 via ‖ŵ‖₁ ≥ ‖ŵ‖₂²/‖ŵ‖_∞.
  - Related: the uncertainty principles of Donoho–Stark 1989 and Tao 2005 (support sizes, prime r). They are not this
    amplitude statement.
- **Scope.** The hypothesis is demanding: it asks for dominance against adversarial phases, and the actual
  modular-exponentiation phases are not adversarial. It does not cover nonlinear statistics, adaptive
  identification, approximate cancellation, or distributional success.
- **The actual signals (E4, §7).** For the actual Gauss-period phases, the strongest of the r peaks of e(ha^t/N) has
  relative mass only 4–8.5/r. Detecting it against the 99% null quantile from m uniform samples succeeds at rate
  ≤ 0.225 for m ≤ r/4, 0.1–0.43 at m = r, and 0.23–0.98 at m = 4r. So Θ(r) samples, even when told where the peak is.
- **Comparison.**
  - Searching for an unknown useful k costs more still.
  - Birthday collisions a^x = a^{x′}, a quadratic statistic, give a multiple of r in O(√r).
  - Generic order computation can beat √r. Sutherland's thesis (MIT 2007, "Order computations in generic groups")
    gives o(√r) for most r, with median exponent ≈ 0.344. The proven generic lower bound is only Ω(r^{1/3}) (see also
    Hhan 2024, arXiv:2402.11269). Shoup/Nechaev bounds concern DL in groups of known order.
  - Black-box permutation models:
    - Cleve (CCC 2000, pp. 54–59). Queries return π^x(y) for x < 2^m, where m is the exponent bit length. The bounds
      are deterministic Ω(√(2^n/m)) and randomized Ω(2^{n/3}/√m) for m ≥ n.
    - Chakraborty–García-Soriano–Matsliah, "Cycle detection, order finding and discrete log with jumps" (ICS 2011,
      pp. 284–297). The bound is ≈ Ω(√(r/log m)/log r + r/m) for jump lengths < m; with unrestricted jumps, order
      finding takes O(log r/log log log r) *queries* (query complexity, not time).
  - Classical periodicity testing from samples: Lachish–Newman, "Testing periodicity" (Algorithmica);
    Ergün–Muthukrishnan–Sahinalp.
- **Ranking.** Linear interference (Θ(r)) is worse than birthday (√r), which is worse than generic order
  algorithms (o(√r), Sutherland).
- **The only escape** is exploitable structure in the phases of F̂(j), i.e. concentration (§1.1). Here the phases are
  Gauss-sum arguments of characters of H, which again encode discrete-log information.

## 3. Q2: why KM / Akavia SFT / GMS do not find the peaks

- **The comb f_c = [a^x ≡ c].**
  - Energy ‖f‖² = 1/r, with r peaks of absolute mass 1/r² each (relative 1/r).
  - SFT over Z_Q: Mansour, SICOMP 24 (1995); Gilbert–Guha–Indyk–Muthukrishnan–Strauss, STOC 2002; AGS 2003; Akavia.
    KM 1993 itself works on the Boolean cube, and our `sft.py` uses KM-style bucket refinement over Z_{2^m}.
  - Akavia's universal SFT (CRYPTO 2009 Thm 4) costs poly(log Q, 1/τ, t) for absolute threshold τ, f into the unit
    ball, and t ≥ L1(f̂). The deterministic version is COLT 2010 / IEEE TIT 60(3) (2014), "…via approximating
    arithmetic progressions".
  - A nontrivial output needs τ ≤ 1/r². Even then the guarantee requires listing all r significant peaks: Ω(r) output.
  - Normalising to unit energy gives √r·f_c, whose sup norm and spectral ℓ¹ norm are both √r (codex). Rescaling cannot
    help.
  - Worse, at density 1/r, o(r) random queries see f ≡ 0, so the estimated energy is 0. E2 confirms this: no output at
    τ ∈ {1/4, 1/16}.
- **Any g.** By Theorem T the best achievable is the largest restriction-class character mass. §1.3 bounds it for each
  analysable class.
- **Positive control.** With a harness-built pure tone g = e(log_a(y)/r), our KM-style SFT (sft.py) recovers r every time
  (E2). The algorithm is fine. The observable is the obstruction.
- **Black box (KNOWN).**
  - Cleve (CCC 2000; arXiv quant-ph/9911124): queries π^x(y) with x < 2^m, m the exponent bit length. The bounds are
    deterministic Ω(√(2^n/m)) and randomized Ω(2^{n/3}/√m). This is not itself a √r bound (codex correction).
  - Chakraborty–García-Soriano–Matsliah, "Cycle detection, order finding and discrete log with jumps" (ICS 2011):
    Ω̃(√r) only when jumps are bounded by m = poly(r). With unrestricted jumps, O(log r/log log log r) queries
    suffice.
  - Generic groups: Sutherland 2007 gives o(√r); the lower bound is Ω(r^{1/3}) (§1.5).
  - Codex's membership-query theorem: with the oracle [r | x] for |x| < 2^b, T queries identify a random prime r ∈ [R, 2R]
    with probability ≤ (1 + Tb/log R)/M. That is Ω(R/b) queries.
  - Aaronson's "Fourier Fishing" (BQP and the polynomial hierarchy, STOC 2010) is the Boolean-cube black-box
    analogue: finding a heavy Fourier coefficient of a function with flat spectrum is classically hard with queries.

## 4. Q3: special a

Every special element we examined falls under order annihilation or is trivial. This is per-family analysis, not a
proved dichotomy. Prop OA's hypotheses (scalar m = N^k·S) cover p ± 1, tori and ECM-type uses. Lucas, torus and
elliptic-curve variants need their own group-order analysis (codex).
- **a = 2, small a.**
  - No speedup known, and fixed bases can have equal local orders (codex: N = 23·89, ord(2) = 11 at both primes, so
    every gcd(2^M − 1, N) ∈ {1, N}).
  - (2/p) depends on p mod 8, so v₂(ord_p 2) is partly determined by p mod 8: the 2-adic RANK analogue.
- **Lucas sequences, norm-one tori, cyclotomic rings** (Z/N)[X]/Φ_k: orders divide p ± 1 or Φ_d(p). This is
  Bach–Shallit 1989 and OA (codex §3).
- **(d/N) = −1** in (Z/N)[√d]: y ↦ y^N is a twisted Frobenius and factors N outright (Prop FROB(a)). It is not an order
  method.
- **Elements "from N".**
  - 1 + √N in (Z/N)[t]/(t²) has known order N.
  - 1 + N in Z/N² has order N, with easy logarithm (Paillier). These are the additive "anomalous" components; their
    characters are computable, but their order N is known and carries no information.
- **The N-power map.** a, a^N, a^{N²}, … cycles with period e = ord_r(N). If e is small, then N^e − 1 is a multiple of
  r and Miller factors N.
  - This needs q^e ≡ 1 (mod r_p) and p^e ≡ 1 (mod r_q): a {p, q} coincidence of OA's second kind, of vanishing density
    (slpcirc Cor SP-N).
  - Finding e generically costs √e ≈ √N.

## 5. Q4: dequantisation

- **Tang 2019; Chia–Gilyén–Li–Lin–Tang–Wang (STOC 2020 / JACM 2022).** These need sample-and-query access and low
  (stable) rank.
  - The exponentiation matrix M_{x,y} = Q^{−1/2}[y = a^x] has r equal singular values, so stable rank r (codex).
  - The unitary U_a: y ↦ ay is a permutation with condition number 1 and full rank. Its eigenvectors
    |u_j⟩ = r^{−1/2}Σ_t η̄_j(a^t)|a^t⟩ are samplable in ℓ² (uniform on the orbit). But querying an entry means
    evaluating η_j, i.e. a discrete log: the same obstruction as Prop BASIS.
- **Gharibian–Le Gall (STOC 2022; SICOMP 52(4), 2023).** QSVT on s-sparse matrices with constant precision is
  dequantised; the guided local Hamiltonian problem is BQP-complete at 1/poly precision. The runtime O*(s^{2d}/ε²)
  and the theorem number are as reported by codex, unverified by the literature critic. Order finding needs eigenphase precision 1/r².
  - Fast-forwarding (U_a^{2^k} is cheap classically) does not help, because what is missing is the eigenvector
    access, not the power.
  - Their BQP-hardness concerns guided local Hamiltonians, not factoring.
- **Aharonov–Landau–Makowsky 2006; Yoran–Short 2007 (PRA 76 042321); Browne 2007.** The QFT is classically simulable
  on product, low-entanglement or tree-like inputs.
  - Yoran–Short (PRA 76 060302(R)) show that the modular-exponentiation stage carries the difficulty (analytic §5).
- **Van den Nest 2011 (QIC 11, "Simulating quantum computers with probabilistic methods").**
  - It discusses Shor/Simon-type circuits explicitly.
  - Its Thm 2: such circuits are classically simulable if the classical postprocessing function has a peaked (Walsh)
    spectrum, found via KM. That is a close cousin of Theorem T's framing (literature critic).
- **Schwarz–Van den Nest 2013 (arXiv:1310.6749).**
  - The pre-QFT state Σ_x|x⟩|a^x⟩ **is** computationally tractable (CT): we can sample it and query amplitudes.
  - The theorem simulates circuits on CT states when the output distribution is (approximately) poly-sparse.
  - Shor's output has r equiprobable peaks and violates sparsity (codex). This is the barrier of §3 in their
    language.
  - **So entanglement is not the missing hypothesis; output sparsity is.** Theorem T says sparsity per branch requires
    a character-correlated measurement basis.
- **Forrelation** (Aaronson–Ambainis, STOC 2015) is the optimal black-box separation of this "Fourier
  correlation" type. Classical algorithms for it: Bravyi–Gosset–Grier–Schaeffer.
- **Bravyi–Gosset 2016 (PRL 116, 250501).** Exponential in T-count; Shor circuits have Θ(n³)-ish T-count.
- **Partial dequantisations of HSP-type problems.**
  - Classical efficiency is known where the oracle is linear (Gaussian elimination), the group order is smooth
    (Pohlig–Hellman), or a computable large-order character exists (anomalous curves: Smart 1999; Semaev 1998;
    Satoh–Araki 1998; Paillier's subgroup).
  - Each is an instance of §1.2's taxonomy.
  - Simon's problem and abelian HSP in general have black-box classical lower bounds of birthday type (Simon 1997;
    for order finding, Cleve 2004; Chakraborty–García-Soriano–Matsliah 2011).

## 6. Barrier statement

**Theorem PF (model barrier; PROVED as the conjunction of T, W, GR-F, DB, UP).**

Setting.
- N = pq, a ∈ G, r = ord(a), i = φ(N)/r, g = gcd(r_p, r_q).
- Write A_j = |F̂(j)|² for the absolute power of F(x) = Ψ(a^x mod N) at j ∈ Z/r. Relative power is A_j/Var(F).
- Call a frequency **exempt** if its order divides g (common-order frequencies; this includes j = 0) or it is the
  Jacobi frequency r/2 (when (a/N) = −1).

Bounds for non-exempt j:
1. **Ψ CRT-local** (leaf-labelled algebraic decision tree over Z/N or a coordinate-represented free (Z/N)-algebra,
   any size, coupled or fresh random tape): Σ_{(r/g)∤j} A_j ≤ 8ε_split. This is informative when g ≤ poly(n), which
   is typical; for large g it is vacuous.
2. **Ψ in the additive class** (ℓ¹ size A over unit frequencies, optionally times the Jacobi symbol), **shifted
   Jacobi**, or a degree-D polynomial phase nondegenerate mod p and mod q: A_j ≤ A²N/r² (resp. N/r², D⁴N/r²).
3. **Ψ a 0/1 event of orbit density ρ:** A_j ≤ min(ρ, 1 − ρ)². So relative power is ≤ min(ρ/(1−ρ), (1−ρ)/ρ), which
   excludes τ-heavy peaks only when ρ < τ/(1 + τ) (or symmetrically). Dense events (e.g. smoothness with large B)
   are handled only heuristically, by Prop SM.
4. **Ψ = the comb:** A_j = 1/r² for all j (relative 1/r).
5. **Every Ψ:**
   - A_j ≥ τ (|Ψ| ≤ 1) with ord(η_j) = d implies a character χ with ord χ a multiple of d and |Ψ̂(χ)|² ≥ τ/i²
     (Theorem T; necessary, not sufficient).
   - A linear filter that isolates one peak against every phase pattern of a flat spectrum must have full support r
     (Prop UP).

Consequences for known algorithms, not lower bounds:
- For typical a (r ≥ N^{1−o(1)}, i ≤ n^{O(1)}) and τ = 1/poly(n), the heavy-hitter guarantees of KM-type SFT,
  Akavia's SFT and GMS produce no non-exempt output in cases 2 and 4, and in case 3 for ρ < τ/(1 + τ).
- In case 1 (with g ≤ poly(n)) they produce none when τ‖F‖² > 8ε_split. If ε_split > 0, O(1/ε_split) direct
  evaluations with gcds already factor N.
- To output anything non-exempt, these algorithms would need thresholds τ ≤ N^{−1+o(1)} (cases 2, 4). By their stated
  complexity bounds, poly(log Q, 1/τ, …), that costs N^{Ω(1)}.
- We claim no lower bound for every algorithm: an output-list guarantee bounds the list size from above by O(1/τ),
  not the running time from below (codex).
- Our SFT runs on the known window Z_Q, Q = 2^{2n+2} ≥ 4N² > 4r², with reconstruction by continued fractions and a
  check a^{r′} = 1 (E2). The unknown r enters only through the Dirichlet-kernel leakage T6.

**What remains open, and why it cannot be closed by a model theorem.**
- The open class: non-CRT-local, non-additive observables that are not rare events, i.e. arbitrary polynomial-time
  computations on the integer representative.
- By Theorem T plus Miller's reduction, constructing one with a 1/poly-heavy peak of order ≥ r/poly for random a would
  give randomized polynomial-time order finding, hence factoring.
- A barrier covering all of them would rule out efficiently computable weak predictors of large-order characters of
  (Z/N)^*. That implies P ≠ NP, since with P = NP such characters are computable via discrete logs. So it is out of
  reach.
- Every concrete member we found (smoothness/rational reconstruction) is relation-based and subject to Prop DB/SM.

Named open subclasses, the sharpest untested corners:
- **(O1) High-degree algebraic preprocessing with an additive readout,** Ψ(y) = e(h·P(y)/N), with P a short
  dense SLP of degree ≫ √N. It is not CRT-local (the readout uses the representative), and Weil is vacuous at that
  degree. Monomial P reduces to the orbit of a^m (OA). Sparse P is Bourgain-type and needs an SP-type exponent
  alignment. Dense high-degree P is open, and it is exactly slpcirc's open door (dense, uniform, non-sparse SLPs)
  seen through an additive character.
- **(O2) Mixed integer/ring computations** that branch on the representative's bits inside a long algebraic
  computation. Neither GR-F nor W applies. No candidate was found.

## 8. Candidate cards

All cards use the BRIEF §4 template, condensed. All are refuted or reduced; none survives.

**C1. SFT on additive observables (Shor phase, MSB/LSB/interval, polynomial phases).**
- Mechanism: run Akavia SFT on F(x) = Ψ(a^x) with Ψ additively concentrated (the HNP analogue).
- Extraction: a heavy frequency gives j/r.
- Lemmas: Theorem T; Gauss and Weil sums.
- Cost: poly(log Q, 1/τ). Its peaks are ≤ A²N/r² ≈ A²i/r (Prop W), so it needs τ ≤ N^{−1+o(1)}.
- Closest prior: Akavia's HNP. The hidden map there is additive.
- Refuting scaling: E1 peaks ≤ 3.4× the random baseline at every size; bound attained.
- **REFUTED for this model.**

**C2. SFT on CRT-local observables (any size; extension rings, curves, tori).**
- Mechanism: a high-degree algebraic Ψ might "interfere".
- Theorem GR-F: visible mass ≤ 8ε_split. Direct gcds win.
- E3: 0 violations in 240 trees.
- **REFUTED for this model (proved).**

**C3. Computable characters (Jacobi; ℓ-th power symbols given π of norm N).**
- Pure tones (T4), but of order ≤ ℓ. They give only [ℓ | r] bits, which for ℓ = 2, 3 are QR/RANK bits.
- Repair would need a large-order computable character, i.e. a discrete-log predictor.
- **Bounded; no mechanism.**

**C4. "Dual index calculus" (SFT on smoothness or rational-reconstruction observables).**
- The heavy peak comes from a pretentious character. It has large order in our data (r/ord median 1–3), so it does
  carry period information.
- Prop DB caps its relative power at ≈ ρ. Prop SM (heuristic) plus the post-hoc data: coherence only when
  π(B) ≲ n/log n, where ρ = N^{−1+O(1/log log N)}. So the cost is N^{1−o(1)}.
- Primal index calculus (L[1/2]) dominates.
- Refuting experiment, if the heuristic is wrong: at fixed n, a B with π(B) ≫ n whose peak/ρ stays ≥ 1/poly. The scan
  shows the opposite trend.
- **REFUTED for this model (DB proved; SM heuristic).**

**C5. Multiplicatively adapted basis (compressed Shor state).**
- In the character basis the state is r product states (Prop BASIS). The basis change needs discrete logs.
- Any classically evaluable basis reduces to C1–C4.
- **Reduced to the main question.**

**C6. Linear interference at strategic x (filters on arithmetic progressions, windows).**
- Prop UP: full support r for worst-case-phase dominance. E4: Θ(r) samples (detection ≥ 0.6 in 3/5 instances, and
  only at m = 4r).
  Birthday √r is better.
- **REFUTED for linear filters against adversarial phases (proved); experimentally for the actual phases.**

**C7. Exponent identities (a^{N+1} = a^{p+q}; a^{N^k}; the N-power cycle).**
- Interval DL of width √N: N^{1/4} (KNOWN).
- A short N-power cycle needs a {p, q} coincidence (OA second kind).
- **KNOWN / OA.**
