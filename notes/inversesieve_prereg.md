## 1. Hypotheses

- **H0 (pseudorandom, my prediction).** The exact uncovered set U(N) and uncovered true factors behave like
  the independent-residue (Poisson) model with respect to every container family tested: short intervals
  of Coppersmith length P^{1/2}, residue classes with modulus ≥ P^{1/2} (AP triples), CRT classes at 1–3
  band primes, low-degree images (class-occupancy deficits mod small primes), additive energy, Lehman
  stationary-point containers, continued-fraction jumps, and held-out halves of the band.
- **H1 (structured).** Some family concentrates U(N) or the uncovered true factor beyond the null, in the
  direction that would make containers cheaper (fewer intervals, more AP triples, missing classes, excess
  energy, Lehman enrichment, cf-jump enrichment, positive dependence between band halves).

Theory prediction (Poisson ledger, `theory.py`): at the real θ = 1/5 design, λ = N^{1/31+o(1)}, so the
expected number of uncovered pairs and of uncovered integer candidates over a dyadic range tends to 0.
Hence no positive asymptotic population of exceptions exists in the model; small-n experiments at
nonempty U(N) test *conditional* structure only, and are a proxy (scaled design, below).

## 2. Designs (frozen; `experiments.configs()`)

- n ∈ {24, 28, 32, 36, 40}. Two band shapes: **M** (log₂Y = ⌊(n+3)/4⌋ + 1, moderate ρ = |V|/ℓ ≈ 0.1–0.4)
  and **S** (log₂Y = n/2 − 4, many primes, ρ ≈ 0.002–0.1, mimicking ρ = λ/J → 0).
- Band = all primes ℓ ≡ 3 (mod 4) in (Y, 2Y]. Weights: signed, sign-symmetric, **including (1,1)**
  (Theorem R's set). H = least height with E_model|U| = |I|∏(1 − |V|/ℓ) ≤ 300 (subject to 2H² < Y).
  Resulting (J, H, |V|): 24M (13,4,22), 24S (22,5,38), 28M (22,6,46), 28S (71,7,70), 32M (37,8,86),
  32S (231,9,110), 36M (71,10,126), 36S (807,11,166), 40M (128,11,166), 40S (2872,13,230).
- Candidate interval I = [⌈√(N/2)⌉, ⌊√N⌋]. Coppersmith length L = ⌊N^{1/4}⌋ = P^{1/2}.
- Lehman containers: centres ⌊√(AN/B)⌋ for positive primitive (A,B), height ≤ h0, 1/2 ≤ A/B ≤ 1,
  half-width ⌊L/2⌋; h0 = least height whose containers cover ≥ 10% of I for N = 3·2^{n−2}
  (h0 = 3, 5, 7, 9, 13 for n = 24..40).
- Instances: seeded sampler of S_n (`sample_pair`, approximately uniform over pairs), 100 N per config.

## 3. Experiments

- **E1 (U(N) structure; operational, sees only N).** Per N: |U|, E_model, survivor trajectory; greedy-optimal
  interval cover number at L/4, L, 4L vs 20 uniform-null sets of equal size; AP triples (gcd of
  differences ≥ L) on ≤ 200 points vs 5 null draws; class occupancy mod r ∈ {3..23} with |U| ≥ 4 r ln r
  (missing classes, χ²) vs null; normalized gaps (KS vs null gaps); pair counts at d ≤ 32 vs the exact
  local-model pair density; integer additive energy vs null; CRT collisions mod the first 1, 2, 3 band
  primes vs uniform samples of the *locally admissible* integers (conditioned on |U|); held-out halves
  (even/odd-index band primes): |U| vs |U₁||U₂|/|I|; Lehman containers: |U ∩ C| vs |U|·measure/|I|.
- **E2 (forbidden sets).** 5 N × 5 band primes per config: additive energies E(F_ℓ), E(R_ℓ(N)) vs random
  sets and vs random *symmetric* sets of equal size (both F and R satisfy A = −A); multiplicative
  energies E×(F), E×(R).
- **E3 (true uncovered pairs vs control).** Per config: 40 random primes p; all uncovered partners q
  (sieved exactly, first on half the band, then on all); up to 5 prime partners per p; 200 control pairs.
  Features: Lehman container membership; L* ≤ X_s := P^{12/31} (cheap Lehman branch at the 6/31
  budget); Dirichlet quality at height 4H; continued-fraction jump B′/B at B ≤ X_s^{1/2}; p's NN-distance
  percentile within U(N); count of U(N) points within L of p vs expectation; held-out ratio
  |partners(full)| / (|partners(half 1)|·∏_{half 2}(1 − |V|/ℓ)).
- **E4 (dchworst e1 worst pairs).** All 172 records of experiments/raw/dchworst_e1.jsonl with their own
  design (first J primes of band(Y), H = h* − 1, signed without (1,1) or positive). Verify uncovered,
  p ∈ U(N); |U| vs model; p's NN percentile; L* percentile among 2000 control pairs of the same n;
  Lehman membership; for signed J ≤ 2, whether p ≡ q (mod ℓ₁).

## 4. Frozen predictions (`analyze.py`; per config unless stated)

- **P1** Σ|U| / Σ E_model ∈ [0.85, 1.15].
- **P2** interval cover ratio at L ∈ [0.97, 1.03] and |z| ≤ 4.
- **P3** AP-triple ratio ∈ [0.75, 1.33] (uninformative if null total < 20).
- **P4** missing classes ≤ null + 3√null + 3, χ² ratio ∈ [0.9, 1.1]. **P4b** CRT(1 prime) collision ratio ∈ [0.8, 1.25] (uninformative if null < 20).
- **P5** pair-count ratio vs local model ∈ [0.85, 1.15]; gap KS p > 10⁻⁴. **P5b** halves ratio ∈ [0.85, 1.15].
- **P6** integer additive energy ratio ∈ [0.9, 1.1].
- **P7** (E2, pooled) median E(R)/E_symnull ∈ [0.85, 1.2] and median E(F)/E_symnull ≥ 1.3; E×(R) = E×(F) exactly (proved identity, Theorem S(d)).
- **P8** (E3, pooled) Lehman RR uncovered/control ∈ [0.7, 1.4] with CI ∋ 1; NN-percentile KS vs U(0,1) p > 0.01; near ratio ∈ [0.8, 1.25]; held-out ratio ∈ [0.85, 1.15]. **P8c** (E1) Lehman U-ratio ∈ [0.8, 1.25]. Reported without thresholds: L* ≤ X_s RR, Dirichlet-quality KS, cf-jump KS, L* KS.
- **P9** (E4, records with J ≥ 16) all uncovered and p ∈ U(N); L*-percentile KS vs U(0,1) p > 0.01; NN-percentile KS p > 0.01. **P9b** signed J ≤ 2 records at the censored maximum have p ≡ q (mod ℓ₁) (the known (1,1)-exclusion artefact).

## 5. Decision rule

- All of P1–P6, P8, P9 hold ⇒ **"no conditional structure detected in any tested container family;
  strong evidence against the inverse-sieve route (kill in the tested families)"**.
- A failure in the *concentrated* direction (H1) in any of P2–P4b, P6, P8, P8c, P9 ⇒ analyze the failing
  cells as a possible lead, test the effect on a fresh seed set (disclosed as exploratory), and report it
  whatever the outcome.
- A failure in the *dispersed* direction or of P1/P5 is reported as a model deviation; it does not help the idea.
