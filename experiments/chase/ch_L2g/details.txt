1. EXACT PROOF OF THE RANK-3 TWO-HYPERPLANE RELATIVE LIOUVILLE LEMMA [proved]
-----------------------------------------------------------------------------
Setting:
Let k be a number field of degree e = [k : Q] with integral basis omega_1, ..., omega_e and basis constant
  C_k := max_{sigma : k -> C} sum_{t=1}^e |sigma(omega_t)|.
Let M = O_k w_1 + O_k w_2 + O_k w_3 subset O_K x O_{K'} be a relative-rank-3 O_k-module with D = 2en embedded
linear forms partitioned by base embedding sigma : k -> C into q = 2n forms L_{sigma, 1}, ..., L_{sigma, 2n} : C^3 -> C.
Identify O_k^3 with Z^{3e} via omega_1, ..., omega_e, and let Box(E) = [-E, E]^{3e} \ {0}.

Lemma (Rank-3 Two-Hyperplane Relative Liouville):
Fix a base embedding sigma_0 : k -> C and two indices 1 <= i < j <= 2n. Set
  tau*_{sigma_0; i, j} := ||L_{sigma_0, i} x L_{sigma_0, j}||_2 / ( 3^{(3e+1)/2} * (C_k E)^{3e - 2} ),
where x denotes the standard cross product on C^3 and ||.||_2 is the Euclidean norm.
Then for EVERY scale s > 0, the dyadic two-hyperplane tube
  R_{sigma_0; i, j}(s) := { a in Box(E) : |L_{sigma_0, i}(a)| < s  and  |L_{sigma_0, j}(a)| < 2 * tau*_{sigma_0; i, j} / s }
has k-span of dimension at most 2 (it is contained in a proper k-subspace W_{sigma_0; i, j, s} subsetneq k^3).

Proof:
If L_{sigma_0, i} x L_{sigma_0, j} = 0, then tau*_{sigma_0; i, j} = 0 and R_{sigma_0; i, j}(s) is empty.
Otherwise, set v := L_{sigma_0, i} x L_{sigma_0, j} != 0 and u* := conj(v) / ||v||_2 in C^3, so ||u*||_2 = 1.
Form the 3x3 complex matrix B whose rows are L_{sigma_0, i}, L_{sigma_0, j}, and u*. Expanding det(B) along row 3 gives
  det(B) = sum_{c=1}^3 u*_c * v_c = ||v||_2^2 / ||v||_2 = ||L_{sigma_0, i} x L_{sigma_0, j}||_2.
Suppose for contradiction that R_{sigma_0; i, j}(s) contains three k-linearly independent vectors a^(1), a^(2), a^(3).
Let A = [a^(1), a^(2), a^(3)] in M_{3x3}(O_k). Since det(A) in O_k \ {0},
  prod_{sigma : k -> C} |det(sigma(A))| = |N_{k/Q}(det(A))| >= 1.
For any sigma and any a in Box(E), each coordinate satisfies |sigma(a_c)| <= C_k E, so ||sigma(a)||_2 <= sqrt(3) C_k E.
- At sigma = sigma_0, apply Hadamard's inequality to the rows of B * sigma_0(A):
  * Row 1 has entries L_{sigma_0, i}(a^(b)) of modulus < s, hence Euclidean norm < sqrt(3) s.
  * Row 2 has entries L_{sigma_0, j}(a^(b)) of modulus < u := 2 * tau*_{sigma_0; i, j} / s, hence norm < sqrt(3) u.
  * Row 3 has entries u*(sigma_0(a^(b))) of modulus <= ||u*||_2 ||sigma_0(a^(b))||_2 <= sqrt(3) C_k E, hence norm <= 3 C_k E.
  Therefore
    ||L_{sigma_0, i} x L_{sigma_0, j}||_2 * |det(sigma_0(A))| = |det(B * sigma_0(A))| < 9 C_k E s u.
- At each of the remaining e - 1 embeddings sigma != sigma_0, apply Hadamard's inequality to the columns of sigma(A):
    |det(sigma(A))| <= (sqrt(3) C_k E)^3 = 3^{3/2} (C_k E)^3.
Multiplying across all e embeddings sigma yields
  ||L_{sigma_0, i} x L_{sigma_0, j}||_2 < 9 C_k E s u * 3^{3(e-1)/2} (C_k E)^{3(e-1)}
                                       = 3^{(3e+1)/2} (C_k E)^{3e - 2} * (2 * tau*_{sigma_0; i, j}) / 2 * 2,
Wait: check factor of 2 in definition!
Wait: 9 C_k E s u = 3^2 C_k E s u, times 3^{(3e-3)/2} (C_k E)^{3e-3} = 3^{(3e+1)/2} (C_k E)^{3e-2} * (s * u)!
WAIT A SECOND! If u = tau* / s (WITHOUT the factor of 2!), then s * u = tau*, giving:
  ||v||_2 < 3^{(3e+1)/2} (C_k E)^{3e-2} * tau* = ||v||_2, a strict contradiction!
With u = 2 * tau* / s, we must include the factor of 2 inside the denominator of tau* when slicing dyadically:
  Set tau_dyadic* := ||v||_2 / (2 * 3^{(3e+1)/2} * (C_k E)^{3e - 2}),
so every point with |L_i(a) * L_j(a)| < tau_dyadic* falls in the dyadic scale s_k = 2^k where s_{k-1} <= |L_i(a)| < s_k,
forcing |L_j(a)| < tau_dyadic* / s_{k-1} = 2 * tau_dyadic* / s_k, so s_k * u_k = 2 * tau_dyadic* = ||v||_2 / (3^{(3e+1)/2} (C_k E)^{3e-2}),
yielding ||v||_2 < ||v||_2, contradiction! QED.

Corollary (Dyadic Two-Hyperplane Subspace Cover):
Suppose 0 < |F(a)| < ( prod_{sigma} prod_{1 <= i < j <= 2n} tau_dyadic*_{sigma; i, j} )^{1/(2n - 1)}.
Since prod_{sigma} prod_{1 <= i < j <= 2n} |L_{sigma, i}(a) L_{sigma, j}(a)| = |F(a)|^{2n - 1}, there exists at least one
same-sigma pair (sigma; i, j) with |L_{sigma, i}(a) L_{sigma, j}(a)| < tau_dyadic*_{sigma; i, j}. If furthermore |L_{sigma, i}(a)|
is not below the single-hyperplane threshold t_{sigma, i} (which already confines a to W_{sigma, i}), then |L_{sigma, i}(a)| lies
in [t_{sigma, i}, M_{sigma, i} * 3 C_k E], covered by K_{sigma, i} <= ceil(log_2(3 C_k E M_{sigma, i} / t_{sigma, i})) dyadic scales
s_k = t_{sigma, i} * 2^k. Thus every capped candidate lies in the union of:
  - D single-hyperplane subspaces W_{sigma, i}, and
  - sum_{sigma, i < j} K_{sigma, i} = O(e n^2 log(H + E)) proper rank-2 k-subspaces W_{sigma; i, j, s_k}.
