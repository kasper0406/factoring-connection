1A. Subspace + Determinant Bound with Coefficient-Height Cutoff (report.txt:7-24, hatch2_codex.out:1-5)
Verdict: CORRECT (with one FIXABLE degree-equality restriction and a sharp quantitative cliff at unbounded unit height).

Audit of Priority (3) steps:
- Exact cancellation identity (report.txt:9-12): For integral a in O_k^m \ {0} with nonvanishing sides, content ideal I = (a_1, ..., a_m), projective height h(a) = (sum_sigma log A_sigma - log Norm I)/e, and d_i(a) = log(M_i A_sigma / |L_i(a)|), direct multiplication gives sum_{i=1}^D d_i(a) = H_tilde + D h(a) - log F_0, where F_0 = |F(a)| / [J (Norm I)^{2n}] and J = Norm(c) Norm(c') is the product of the two generator ideal norms. Note that d_i(a) >= -log m can be negative (e.g. omega_{i,j} = 1, a = (1,...,1) gives d_i = -log m), which does not break report.txt:18 or 21 because non-selected places only use an upper bound d_i <= G/(2D) or d_i <= gamma. Note also that report.txt:11 silently repairs a typo in notes/subthird_results.md:135 (which wrote log N(c) instead of log[N(c)N(c')]); in Theorem KH, [c^T x c'^T : S] >= N puts both c^T and c'^T into the ambient covolume, so J = N(c)N(c') is exact.
- "At most D proper k-subspaces" (report.txt:14-16): CORRECT. Fix i in {1,...,D} and cutoff u >= 0. If m k-independent vectors a^{(1)}, ..., a^{(m)} with h <= u satisfy d_i > tau(u) = r(u + (1/2)log m), their determinant Delta in k \ {0} lies in I_1 ... I_m, so prod_sigma |sigma(Delta)| >= prod_l Norm(I_l) >= exp(-e m u) prod_{sigma,l} A_sigma(a^{(l)}). At sigma = i|_k (promoting sigma(a^{(l)}_j) to C^{m x m} when i is complex over a real place sigma of k), replacing a column attaining M_i = max_j |omega_{i,j}| > 0 by L_i / omega_{i,j*} preserves det while bounding that normalized column's l_2-norm by sqrt(m) exp(-tau(u)) and the other m-1 columns by sqrt(m), giving Hadamard product < (sqrt(m))^{m-1} (sqrt(m) exp(-tau)) m^{(e-1)m/2} = m^{em/2} exp(-tau) = exp(-e m u), contradiction. Even when one projection rank s_1 < m (allowed by Theorem KH since max(s_1, s_2) >= m/2), M_i > 0 still holds because no side vanishes identically. The Plucker height bound t u + (t/2)log t (report.txt:16) is also exact since minor ideal inclusion I(p) subseteq I_1 ... I_t implies Norm I(p) >= prod Norm I_l.
- Required embedding count Omega(sqrt(x)/log x) (report.txt:18, hatch2_codex.out:1): CORRECT at bounded projective height h(a) <= u = O(1). Outside the <= D spaces, if S_+ = {i : d_i > G/(2D)} for G = H_tilde - log Y > 0, then G <= sum d_i <= |S_+| tau(u) + (D - |S_+|)(G/(2D)) <= |S_+| tau(u) + G/2, so |S_+| >= G / (2 tau(u)). At D ~ sqrt(x), r = em ~ x^{1/4}, u = O(1), and log Y = o(mx/n), Theorem KH gives G = Theta(mx/n) = Theta(x^{3/4}) while tau(u) = Theta(r log m) = Theta(x^{1/4} log x), giving |S_+| = Omega(sqrt(x)/log x). At the exact L[1/4] balance n ~ sqrt(x/log x), m = x^{1/4+o(1)}, m cancels in (mx/n)/(m log x), forcing Theta(D) embeddings to cancel (unless G > D tau(u), where the <= D spaces cover all points).
- Fixable issue and scope limits:
  (i) FIXABLE (report.txt:5, 11): Equal relative degrees n = [K:k] = [K':k] are assumed in (Norm I)^{2n}. Rescued Theorem KH (notes/subthird_results.md:128) allows unequal degrees (n_1, n_2); replace (Norm I)^{2n} by (Norm I)^{n_1 + n_2}, D = e(n_1 + n_2), and n = max(n_1, n_2) in KH.
  (ii) Unbounded height cliff (report.txt:20-21): Common-unit scaling a |-> eta*a (eta in O_k^x) preserves h(a), but independent coordinate units a = (1, eps_1^{t_1}, eps_2^{t_2}) or multi-cone weighted LLL vectors have large projective height h(a) ~ x^{1/4}. There, dyadic partitioning only bounds log F_0 when q <= D/(2r) embeddings have d_i > gamma. At L[1/4] parameters D ~ (x/log x)^{1/2}, r ~ x^{1/4}(log x)^{3/4}, D/(2r) ~ x^{1/4}(log x)^{-5/4} << sqrt(x)/log x: as soon as a 1/(2r) fraction of embeddings cancel, (D - 2qr)h turns negative. Moreover, parity rank inside the proper subspaces remains uncharged (report.txt:24).

1C. Cubic Unit-Orbit Rational-to-k Cover Lemma (report.txt:36)
Verdict: CORRECT. Since u = 4 cos^2(2*pi/7) has three distinct positive conjugates, Descartes' rule forbids any <= 3-term rational relation among three powers of u; pigeonhole on 0 <= j <= 2t places k*a inside one of t proper Q-subspaces, whose k-core is proper.

1D. S-Unit Steering & Exhaustive Audit (report.txt:38-51, steer.py, audit.py)
Verdict: CORRECT measurements, narrow regime. Exact resultants and PARI idealfactor checks are sound (and granting the cubic root mod N for free only helps the attacker). However, on (1, T, T^3) (steer.py:133), T^3 sets a baseline Mahler log-norm of (18/n) log N (4.50 log N at n=4; 3.60 log N at n=5), whereas coordinate deletion (1, T, 0) has (6/n) log N < 2 log N. Thus 0 hits below N^2 was unavoidable at |U|=100 and n in {4,5} unless extreme non-generic clustering occurred.

2A. Per-Depth Weighted Theorem J (report.md:9-27)
Verdict: CORRECT.
Audit (Priority 5): Rescaling E = t = log V and setting theta = 1 - (log u - 2 log log x)/log B, Rankin on z <= 3 X_0 (valid for large x since V <= exp(O(F_{1-beta})) = o(X_0) for beta > 0) and Markov exp(2*theta*(S(z) - t)) give log mean <= -(1-theta)x + (1-2*theta)t + sum_{q<=B} log M_q + O(1) (weights at q > B may be zeroed WLOG since v_q(z) = 0 on B-smooth z). Splitting at q <= Z = log x or D_q >= 1/16 via Cauchy-Schwarz (2 sum_{k<=j} h_{qk} - j <= D_q, and <= -j/2 for j >= 16 D_q) and Taylor-expanding -log(1 - q^{-theta(1 - 2 sqrt(D_q))}) on the rest yields sum log M_q <= theta*t + o(F_{1-beta}). Crucially, B^{1-theta} = u/(log x)^2 = O(F_{1-beta}/(log x)^2) and (1-theta)t = O(x^{1-2*beta}(log x)^{2*beta}) = o(F_{1-beta}) for all 0 < beta < 1, so window size +t cancels -theta*t even when V >> 1/rho(u). Cleaner and more general than notes/sihard_results.md:474.

2B. Taylor Divisibility Lattice Construction (report.md:28, experiment.py:76-115)
Verdict: CORRECT. With v_q(d_i) = sum_{k>=1}(h_{qk} - i)_+, at v_q(T + C) = j row i supplies sum_{k>=1}(h_{qk} - i)_+ + i*j >= sum_{k=1}^j max(h_{qk}, i) >= sum_{k=1}^j h_{qk} powers (not even requiring nonincreasing h_{qk}), and log-det sums to (1/2) sum(h_{qk}^2 + h_{qk}) log q for d >= max h_{qk}.

2C. Split-Prime Folding Obstruction & Projective Johnson Bound J_2 (report.md:32-38)
Verdict: CORRECT (minor precision needed at report.md:36: each prime in the ideal product must satisfy q > max(deg_U P, deg_V P) + 1; e.g. U^2 - 1 vanishes on F_3^x without UV | P, implicitly covered by "such primes"). 2D. M2 Rational Reconstruction & Timing Claim (experiment.py:205, 226; report.md:44-55; hatch1_codex.out:7)
Verdict: Traversal lower bound binom(n, m) (report.md:55) is CORRECT (since B^m <= 2K^2 < 4K^2); implementation and 96-bit timing comparison (experiment.py:205, report.md:49) are FIXABLE / FLAWED AS BENCHMARKED.
- Specific step (experiment.py:205): forced_moduli hardcodes limit = 4*K*K (16,384 for K=64) instead of Lemma W's 2*K*K*B, pruning whenever modulus * q > 4*K^2.
- Counterexample from C-H1's own runs.jsonl:22 (96 bits, rep 3): witness (u,v) = (41, 30) gives 4093-smooth Q = 2 * 29 * 31 * 127 * 601 * 1031 * 2203 * 2879 with good-prime part M_good = 448696531115627231. Its largest divisor <= 8192 is 31*127 = 3937 and its smallest divisor > 8192 is 29*601 = 17429 > 16384, so forced_moduli misses it. Across all 24 runs, 15/15 missed witnesses (80 - 65 = 15) have M_good > 2K^2 and a divisor in (2K^2, 2K^2*B], but none in (2K^2, 4K^2]. Asymptotically at B = L[beta], (2K^2, 4K^2] misses 1 - o(1) of smooth witnesses; restoring limit = 2*K^2*B at 96 bits increases branches from 12,478 to 7,082,790 (567x), reversing "5.96 ms vs 10.27 ms" into >300x slower than sieving.
