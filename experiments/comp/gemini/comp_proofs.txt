EXTENDED PROOFS FOR THE COMPENSATION ROUND (comp_g)

1. Theorem 1 (Existence of Reduced Linked O_k-Modules in H = O(x/T) with lambda ~ m log m at u ~ D Embeddings,
and Why They Still Satisfy the Compensation Dichotomy) [proved].

Let k = Q(sqrt(2)) (e = 2), m >= 3, n >= m + 2, and take linear poles R_j(T) = T - (4 + j) for j = 1, ..., m - 2
(total pole degree p = m - 2) with unit-remainder polynomial P(T) = 1 + R(T) U(T), Q(T) = P(T) + j_0 (T - b) R(T),
where U(T) is monic of degree q = n - m + 2 with centered base-b digits (b ~ N^{1/q}), P(b) == Q(b) == a (mod N),
and P^2 - 2, Q^2 - 2 are irreducible. Let c_1 = nextprime(4 m + 2) coprime to N, and set
  v_tilde = (c_1, alpha, (P // R_1)(alpha), ..., (P // R_{m-2})(alpha))  (and v'_tilde on Side 2).

By Alon and Vu (Combinatorica 17 (1997), Main Theorem / Corollary 2.3), there exists an invertible matrix
B_0 in {-1, 0, 1}^{m x m} with ||B_0^{-1}||_max = exp((m/2) log m - O(m)). By Hadamard's inequality on (m - 1) x (m - 1)
minors of B_0, ||adj(B_0)||_max <= (m - 1)^{(m-1)/2} = exp((m/2) log m - (1/2) log m). Since ||B_0^{-1}||_max =
||adj(B_0)||_max / |det B_0|, we obtain unconditionally:
  1 <= |det B_0| = ||adj(B_0)||_max / ||B_0^{-1}||_max <= exp(O(m)).                               (1)
Permute rows of B_0 so that column 1 of C* := g_0^{-1} adj(B_0) in Z^{m x m} (g_0 = gcd of entries of adj(B_0),
Delta* := |det B_0|/g_0 <= exp(O(m)), gcd(Delta*, N) = 1) attains ||C*||_max = Delta* K_m with
K_m = exp((m/2) log m - O(m)), and define the twisted generator module w := C* v_tilde, w' := C* v'_tilde.

(a) Height H(w) = O(x / T): Since ||P||_inf <= b * (m + 4)^m, Mahler's bound gives sum_{i=1}^D log^+|alpha_i| <=
4 log b + O(m log m), so by Markov's inequality at least D - O(m + log b) = (1 - o(1)) D embeddings satisfy
|alpha_i| <= 2 (and hence |alpha_i - (4 + j)| >= 3). At every such embedding i:
  |v_tilde_1(alpha_i)| = c_1 >= 4 m + 3,   |v_tilde_2(alpha_i)| <= 2,
  |v_tilde_{2+j}(alpha_i)| = |+-sqrt(2) - 1| / |alpha_i - (4 + j)| <= (1 + sqrt(2)) / 3 < 0.81,
so sum_{l=2}^m |v_tilde_l(alpha_i)| <= 2 + 0.81(m - 2) < m + 2 < c_1 / 2. Consequently:
  (1/2) c_1 Delta* K_m <= M_i(w) <= (3/2) c_1 Delta* K_m.
At the 4(m - 2) pole-adjacent embeddings alpha_* near 4 + j, |U(4 + j)| <= b (m + 5)^q gives log M_*(w) <=
log b + n log(m + 5) + (1/2) m log m + O(m). Since (Delta* c_1) O_K subseteq c_w subseteq O_K gives
0 <= log J_w <= D log(Delta* c_1) = O(D m), summing over all D = 4n embeddings yields:
  H(w) = sum_{i=1}^D log M_i(w) - log J_w <= (1/2) D m log m + 4(m - 2) log b + D m log(m + 5) + O(D m) = O(x / T).

(b) Simultaneous loss at u = (1 - o(1)) D embeddings: Because B_0 w = +-Delta* v_tilde identically, at every
embedding i with |alpha_i| <= 2 the m independent ternary rows of B_0 satisfy |B_{0,l} . w(alpha_i)| =
Delta* |v_tilde_l(alpha_i)| <= Delta* c_1, so t_i(w) <= Delta* c_1 and
  lambda_i(w) = log(M_i(w) / t_i(w)) >= log(K_m / 2) = (1/2) m log m - O(m)
at u = D - O(m + log b) = (1 - o(1)) D embeddings simultaneously!


2. Theorem 2 (Submodule-KH Compensation Lemma and Covolume Obstruction Against Conjugate Absorption) [proved].

(a) Submodule-KH Compensation Lemma for shared/pool-aligned bases:
Let M = sum_{j=1}^m O_k w_j subset K x K' be ANY reduced linked O_k-module of relative rank m, larger projection
dimension s >= m/2, KH degree T = 2 ceil(2n / s) + 1, and generator-ideal norm product J = N(c) N(c'). Let
B in A^{m x m} be ANY invertible ternary matrix (det B != 0), and let M_B := sum_{l=1}^m O_k (B w)_l subseteq M be
the linked rank-m submodule generated by the rows of B, with local maxima M_{B,i} := max_{1<=l<=m} |L_i((B w)_l)|
and ideal-norm product J_B = N(c_B) N(c'_B). Because k . M_B = k . M, M_B has the exact same projection dimensions
and KH degree T as M, and (det B) c subseteq c_B subseteq c implies
  0 <= log(J_B / J) <= (D / e) log |N_{k/Q}(det B)| (since c_B subseteq c implies N(c) divides N(c_B)).
Applying Ideal-Relative Theorem KH (notes/subthird_results.md:136) directly to M_B gives:
  sum_{i=1}^D log M_{B,i} - log J_B >= (x - D log(C_k D)) / T,
and therefore:
  sum_{i=1}^D log M_{B,i} - log J >= (x - D log(C_k D)) / T + log(J_B / J) >= (x - D log(C_k D)) / T!     (2)
Notice log(J_B / J) >= 0 HELPS the lower bound (since M_B subseteq M implies c_B subseteq c, so N(c_B) >= N(c),
hence J_B >= J ALWAYS)!
Now partition {1, ..., D} into U_B (u embeddings where B witnesses M_{B,i} <= e^{kappa_i} t_i) and U_B^c (the
remaining D - u embeddings). On U_B^c, M_{B,j} <= C_k m M_j = C_k m e^{lambda_j} t_j. Substituting into (2) yields
the exact Submodule-KH Compensation Inequality:
  Q = sum_{i=1}^D log t_i - log J >= (x - D log(C_k D)) / T - sum_{i in U_B} kappa_i - sum_{j notin U_B} lambda_j
                                     - (D - u) log(C_k m).                                                 (3)
Consequences:
  (i) Whenever a single ternary basis B attains t_i up to e^{O_k(m)} on u = D - o(D) embeddings (as in Theorem 1's
      M3_adjZ and Gemini's C3 where D - u = O(m + log b) = o(D)), Cramer's bound lambda_j <= (e/2) m log m + O_k(m)
      on U_B^c gives sum_{j notin U_B} lambda_j = o(D m log m) = o(x / T), proving Q >= (1 - o(1)) x / T - O_k(D m)
      UNCONDITIONALLY!
  (ii) Even if u = D/2 (e.g. B witnesses t_i at all embeddings over one base place sigma_1 of k = Q(sqrt(2)), as in
       M4_uniOk), any candidate z in A^m avoiding the D prefix hyperplanes on sigma_1 has z_tilde := B^{-T} z; if
       det B in O_k^* is unimodular over O_k, M_B = M as O_k-modules and z |-> z_tilde is a bijection preserving all
       proper k-subspaces and norms, reducing non-subspace norm bounds on w = B^{-1} v_tilde to v_tilde!

(b) Covolume / Minkowski obstruction against two-place conjugate absorption over O_k [proved]:
Suppose over k = Q(sqrt(2)) one tries to make Q << 0 via base-field conjugates: find u in O_k^m \ {0} and two
invertible ternary matrices B_1, B_2 in A^{m x m} with delta_r := |sigma_r(det B_r)| <= m^{-gamma m} (r = 1, 2)
such that ||sigma_1(B_1) sigma_1(u)||_inf <= tau_1 and ||sigma_2(B_2) sigma_2(u)||_inf <= tau_2. In R^m x R^m,
if m k-independent vectors u^(1), ..., u^(m) in O_k^m satisfy ||sigma_1(B_1) sigma_1(u^(l))||_inf <= tau_1 and
||sigma_2(B_2) sigma_2(u^(l))||_inf <= tau_2, form the m x m matrix U in M_m(O_k) with columns u^(l) (det U != 0):
  1 <= |N_{k/Q}(det U)| = |det sigma_1(U)| * |det sigma_2(U)|
    = (|det(sigma_1(B_1) sigma_1(U))| / delta_1) * (|det(sigma_2(B_2) sigma_2(U))| / delta_2)
    <= (m^{m/2} tau_1^m / delta_1) * (m^{m/2} tau_2^m / delta_2).
Since delta_1 >= (C_k sqrt(m))^{-m} and delta_2 >= (C_k sqrt(m))^{-m} by Hadamard at the opposite base place,
  (tau_1 tau_2)^m >= delta_1 delta_2 m^{-m} >= C_k^{-2m} m^{-2m}  =>  log tau_1 + log tau_2 >= -2 log(C_k m)!   (4)
Equation (4) proves that across m k-independent O_k-vectors, negative log-thresholds at sigma_1 (-m log m) MUST be
compensated one-for-one (+m log m - O(log m)) at sigma_2: conjugate absorption of -Theta(m log m) is impossible!


3. Theorem 3 (Support-Width Obstruction for Pole Clustering and General-Pole Divided-Difference Identity) [proved].

(a) Support-Width Lemma (killing small-cluster pole splitting) [proved]:
Let y in C^m \ {0} and A in A^{m x m} (det A != 0) satisfy lambda := log(||y||_inf / ||sigma(A) y||_inf) >=
gamma m log m (gamma > 0). Put J_big := {j in {1..m} : |y_j| >= e^{-lambda/2} ||y||_inf} and s_big := |J_big|.
Writing sigma(A)_{J_big} y_{J_big} = sigma(A) y - sigma(A)_{J_big^c} y_{J_big^c}, the right-hand side has l_inf-norm
<= (e^{-lambda} + C_k m e^{-lambda/2}) ||y||_inf <= 2 C_k m e^{-lambda/2} ||y||_inf. Since sigma(A) is invertible,
sigma(A)_{J_big} has full column rank s_big and contains an invertible s_big x s_big minor M_sub in A^{s_big x s_big}.
Applying the Cramer / product-formula bound (proof.txt:15) to M_sub gives:
  ||y||_inf = ||y_{J_big}||_inf <= C_k^{e s_big - 1} s_big^{e s_big / 2} (2 C_k m e^{-lambda/2} ||y||_inf),
hence
  lambda / 2 <= (e / 2) s_big log s_big + O_k(s_big + log m)  =>  s_big >= (gamma / e - o(1)) m.          (5)
Thus NO partition of poles into small clusters can confine amplitude >= e^{lambda/2} to o(m) coordinates: at least
Theta_{k,gamma}(m) coordinates must simultaneously exceed e^{lambda/2} ||sigma(A) y||_inf!

(b) Exact General-Pole Divided-Difference Identity (generalizing linear-pole rho-inflation to arbitrary R_j) [proved]:
Let R_j(T) in O_k[T] be ANY monic squarefree pole polynomial of degree d_j >= 1, with roots beta_{j,1}, ...,
beta_{j,d_j} under sigma : k -> C, and let f_sigma(T) = sigma(P)(T) - sigma(sqrt(2)) = prod_{l=1}^n (T - alpha_l).
By Lagrange interpolation of S_{j,sigma}(T) - sigma(sqrt(2)) = f_sigma(T) mod R_{j,sigma}(T) at {beta_{j,nu}} and
evaluation at T = alpha_i (where f_sigma(alpha_i) = 0), the quotient generator satisfies identically:
  w_{2+j}(alpha_i) = f_sigma[alpha_i, beta_{j,1}, ..., beta_{j,d_j}]
                   = sum_{nu=1}^{d_j} [ prod_{l != i} (beta_{j,nu} - alpha_l) ] / R'_{j,sigma}(beta_{j,nu}).  (6)
(For non-squarefree R_j, the Newton divided difference f_sigma[alpha_i, beta_{j,1}, ..., beta_{j,d_j}] holds by
continuity/confluence.) Whenever u roots alpha_l are separated from a pole root beta_{j,nu_0} by scale rho (either
|alpha_l| ~ rho >> |beta_{j,nu_0}| as in Gemini's C3, or |alpha_l| <= eps << 1 with compensating large roots of
product B >= eps^{-u} as in Codex's quadratic-pole family R_j = T^2 - r_j^2, dd/codex/proof.txt:49), at the
pole-adjacent root alpha_* near beta_{j,nu_0} only the nu = nu_0 summand in (6) drops the tiny factor
(beta_{j,nu_0} - alpha_*), giving |w_{2+j}(alpha_*)| = (1 - o(1)) prod_{l != *} |beta_{j,nu_0} - alpha_l| /
|R'_{j,sigma}(beta_{j,nu_0})| and forcing Q-inflation across all Theta(m) heavy poles required by (5).
