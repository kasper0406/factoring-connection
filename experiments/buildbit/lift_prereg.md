# Follow-up arithmetic validation

The central-binomial construction is a proof-derived follow-up after the original data were analyzed. It has no new discovery endpoint. This registration precedes running the lift, class-form and public alias checks below.

* Draw 128 fresh T1 products per r class per size at 40, 60, 80 bits using the sampling rule in prereg.md and seed stream 20261126*10000+10*n+7. Starting from r mod 8, select each numerator multiplier by a binary search on powers of c=N/a^2 mod 2^j. Query the zero predicate using an explicitly factor-backed Kummer oracle. Stop before the modulus reaches sqrt(N/2) and enumerate the remaining candidates in the balanced interval by trial division. Record the selected h, bit correctness, unintentional proper binomial gcds, intended final factor recoveries, and maximum query count. A single mismatch refutes the implementation. Test the T1 j=4 closed formula h=1 or 3 as well. Validate on small pairs with exact integer binomial coefficients in place of the oracle and count those evaluations. This is a reduction test, never a claimed factor-blind coefficient evaluator.
* Validate the imaginary class-group construction by enumerating reduced forms of its odd discriminant and squaring them with PARI on small T0 pairs (5 <= p < q < 2p, q < 160). Run for squarefree and non-squarefree 4N-1. Compare square membership with the bit. Proof is the primary endpoint.
* Test the candidate coefficient compression by folding the central coefficient modulo X^L-1. For L=8,16,32 use the fresh 40/60/80-bit T1 inputs and the j=4 closed formula; obtain the cyclic middle coefficient by public modular exponentiation. Check its zero/unit/proper-gcd counts by class. A viable exact replacement must agree on every input with no proper gcd. This is a secondary falsification check for exact equality of zero decisions; no discovery pass can be claimed from it. Flag all proper gcds and preserve counterexamples.
