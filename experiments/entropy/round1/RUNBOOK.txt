Reproducing the semiprime experiment

Run ./run.sh from this directory on the original arm64 macOS toolchain. It verifies the preregistration checksum before doing any experimental work. The run uses C++17, GMP, uv and Python 3.12.7. The script pins the Python dependencies, compiles the three C++ components and regenerates the data, statistics, audits and figure locally. GMP_PREFIX selects a different GMP installation. The original local virtual environment is .venv. C++ uniform distributions can differ across standard libraries. The saved factor draws allow a numerical replay independent of that sampling detail.

PREREGISTRATION.md, PREREGISTRATION.sha256 and registered.utc record the protocol and its local lock time. catalog.tsv defines all 12,000 tests. For a unary row, column a is a zero-based index in gates.tsv and b selects a bit projection. Projection indices 0–7 select that numbered bit, 8 and 9 give parity of the low 8 and 16 bits, 10 gives full parity, 11 indicates a negative Jacobi symbol and 12 indicates a zero Jacobi symbol. For binary rows, a and b refer to preceding unary test IDs. targets.tsv gives every bit position, GL mask and definition by size. For the fraction gates, frac16 means floor(65536 times the fractional part).

Each data/N_SPLIT.rows is a headerless little-endian uint64 array with four columns (p, q, reference p, reference q). The prefix is the high eight bits of the primary product. D has 100,000 rows. V and C have 50,000 each. The .g files contain 50 little-endian uint16 projection words for each primary, and .f contains two uint8 flag masks for each pair. Bits 0–6 denote a semantic gate or its checked offset, a Lucas-ladder state, a continued-fraction state, Fermat, Lehman, Pollard p−1 and Williams p+1, respectively. A zero mask means all registered checks passed without a split. The witness files belong to catalog construction. Sample generation, gate evaluation and discovery scoring have separate programs.

For each size and split, results/N_SPLIT_counts.npz contains pairs[K,2] and counts[K,4,4]. Each pair holds the catalog test ID and target ID. The middle dimension orders the views as raw, raw_clean, matched and matched_clean. The last dimension orders the counts as (X,Y) = (0,0), (0,1), (1,0), (1,1), using the catalog orientation before any sign choice. A matched row requires disagreement between the primary and reference labels. The raw clean view requires an unflagged primary. The matched clean view requires both members to be unflagged. These extra conditions are symmetric between the two members when matching and preserve within-bin label fairness. Surviving pairs appear in both holdouts, indexed by their original catalog and target IDs.

results/N_SPLIT_stats.npz contains stats[K,4,6], aligned with the counts, and named axes fields and views. The six fields give signed advantage, its lower and upper exact 95% Clopper–Pearson bounds, plug-in mutual information in bits and its lower and upper conservative finite-sample 95% bounds. The latter use six simultaneous exact binomial intervals for two margins and four joint cells. Empty views have NaN point estimates and full parameter-space bounds. Intervals are pointwise. Discovery and replication use their own family-adjusted decision thresholds.

For example, run this with .venv/bin/python from this directory to retrieve test 386 against prime bit 3 on 96-bit confirmation data.

    import numpy as np
    counts = np.load('results/96_C_counts.npz')
    i, = np.flatnonzero((counts['pairs'] == [386, 4]).all(axis=1))
    print(counts['counts'][i, 3])
    print(np.load('results/96_C_stats.npz')['stats'][i, 3])

results/survivors.tsv freezes ID, target, sign and strongest discovery cell. results/survivor_measurements.tsv.gz is a tab-separated export for all survivors at every size, split and view, with counts, MI and both catalog and discovery-oriented advantage. results/scaling.tsv gives model amplitudes at n=24, decay exponents, weighted residual sums of squares and the four replication p-values. The fitted curves are A(n/24)^(-k) and B 2^(-beta(n-24)). The last columns and pass indicators apply the registered criteria.

results/planted.tsv, low_bit_controls.tsv and shuffle.tsv contain the controls. The planted table gives the observed agreement, intervals, individual one-sided power and power for the positive tail of the two-sided discovery decision. The shuffle screen uses a separate Bonferroni threshold of .05/(12,000 × 8). Its sentinel p-value is two-sided and conditions on the per-prefix margins by convolving hypergeometric distributions. Empty low-bit controls occupy their preregistered Holm slots with p=1. results/uniform_residue_null.tsv records a post hoc calibration using exactly fair low-bit targets compatible with each product modulo 16. results/power_planning.tsv gives separate synthetic power simulations. Its planned sample sizes are rounded design points with verified power of at least 80%.

results/sample_counts.tsv and overlap.tsv describe primary sample repetition and cross-split overlap. split_flags.tsv and flag_mask_counts.tsv give counts by reason and by joint flag mask. audit.json records independent arithmetic, exact population and statistic checks. semiprime_distinct.json and discovery_equivalence.tsv give full-discovery distinctions among catalog tests. The supplementary population24.npz covers every grammar test and target over the entire admissible 24-bit population. It contains integer raw counts, prefix-integrated matched joint probabilities, discordance rates, advantages and mutual information. The census input population24.rows repeats the primary factors in its last two columns for gate evaluation. The matching calculation integrates over every possible reference in the prefix. Additional descriptive follow-ups are in exact24.json and low1_diagnostic.tsv. confirmation_and_power.png shows the first strongest hit and planted-control power. The left-hand error bars are pointwise 95% exact intervals and the right-hand panel uses clean matched discovery rows.

The repeat-run checksums cover the numeric inputs, intermediate bit projections, split masks, measured contingency tables, statistics, control tables and fit decisions. results/replay.log reports timing. results/replay_check.log records the comparison to the first execution.

To extend the grammar, keep the integer gate order in gates.cpp and grammar.py aligned and update the gate count and binary shape. The frozen catalog and original results can be reconstructed with the sources recorded in source.sha256.
