# Cheap tests of balanced semiprimes — prospective registration

Locked before any data, witness evaluation or outcome inspection. The compute limit is three hours. Work and outputs live here. A hash and UTC timestamp accompany this file. All sizes, splits, grammar families, screening and lead decisions below are fixed.

## Population and splits

Use n = 24,32,40,48,56,64,80,96. Draw each prime independently and uniformly from the h=n/2 bit primes by uniform odd rejection (a complete prime table is equivalent where cheap). Reject equal factors and products with bit length different from n. Sort as p<q. Independent draws with replacement are essential at 24 bits. Report within/between-split repetition. Each size gets 100,000 discovery, 50,000 validation and 50,000 confirmation primary products. In addition give every primary its own independent reference drawn from the same distribution conditional on the same top eight product bits. Generate references by a separate iid stream and route them to waiting rows by prefix. Unused tail draws are discarded. Derive independent seeded streams from SHA-256 of ent-c-20261123-v1 and named purposes, sizes, splits. No prior datasets. Holdouts are scored only for discovery survivors plus controls.

## Targets and size control

Use the second highest prime bit, bit floor(h/2), low bits 1,2,3 (bit 1 encodes chi4), four seeded GL masks on nonconstant bit positions, negative Legendre symbols (ell|p) at 3,5,7,11, indicators p mod 5 = 1 and p mod 7 in {1,2,3}, and bits 0,1,2 of floor(8p/q). Bit 0 of p is constant and excluded. For each target retain matched pairs whose true target bits disagree and score the primary bit. Exchangeability makes this target fair in every prefix. This controls size between bins, with residual within-bin size structure possible. Score four views: raw primary, raw primary excluding flagged rows, matched, and matched with both members unflagged. Report all views; discovery selection uses the two matched views. Raw agreement can include the majority-label baseline.

## Grammar and catalog

Integer terminals include N, bases 2,3,5,7 with exponents N,(N-1)/2,N-1,N+1, Lucas V_N at (3,1),(5,1),(3,-1), and (x^N+c)^N mod N for x=2,3 and c=-1,+1. Include floor(N/k), N mod k for k=3,5,7,11,13,16,31; isqrt(N); floor(2^16 frac(sqrt(N))); floor(2^16 frac(N sqrt(d))) for d=2,3 (exact integer square root); four CF partial quotients after a0 for sqrt(N) and N/2^h (zero-pad terminated expansions). Project integer outputs to bits 0 through 7, parity of low 8, low 16 and full value, negative and zero Jacobi (value|N). Form unordered distinct pairs of unary bits and combine by XOR, product (AND), and the nonzero bit of their sum (OR). Assign depth by the longest path: N depth 0, named gates depth 1, nested gates depth 2, each projection and binary combination adds 1. All surviving unary projections enter. Draw binary forms by deterministic shuffled enumeration, balancing by operation and available depth classes, up to 12,000 total. Remove constant and equivalent truth vectors on a fixed independent panel of 512 odd, nonsquare n-bit integer witnesses spread across the eight sizes, before seeing sampled semiprimes. This certifies distinct N-only functions on the witness domain. Save catalog and depth counts. No learned thresholds or target-dependent grammar tuning.

## Inference and scale

Save the full binary contingency table or equivalent sufficient counts for every measured (test,target,n,split,view). Report signed advantage = agreement fraction minus 1/2 and plug-in mutual information in bits. Per-cell 95% advantage intervals are exact two-sided Clopper-Pearson (CP). For MI give a conservative finite-sample 95% interval: simultaneously cover both Bernoulli margins and the four joint probabilities with six Bonferroni CP intervals; bound the marginal entropies and joint entropy on that box. Clip to [0,1]. Empty views have undefined estimates and full intervals. No asymptotic interval is described as exact.

Discovery: two-sided exact Binomial(m,1/2) test on agreement. Bonferroni family includes all catalog tests × targets × eight sizes × two matched views at family alpha .05. A test-target pair survives if any cell passes. Freeze sign by smallest two-sided p (ties by increasing n then inclusive before clean). A negative direction complements the test. Repeat every survivor at every n in both holdouts, even if validation fails. Selection uses no holdout information.

A lead requires positive oriented advantage in the clean matched view at BOTH 80 and 96 in BOTH holdouts, all four one-sided exact p <= .05/(4 max(1,number of discovery survivors)). Fit oriented clean matched confirmation advantages to c n^-k versus c 2^(-beta n), c>=0, via weighted least squares with weights 4m. Search k=0,0.01,...,8 and beta=0,0.001,...,0.5; analytic nonnegative amplitude for each grid point. Center models at n=24 for numerical conditioning. Use sizes with m>=100, require at least five, weighted RSS_poly <= chi-square(.95, sizes-2) and RSS_exp - RSS_poly >= 2. k=0 permits persistent advantage, but identical flat models cannot meet the model separation criterion. Report both fits for all survivors where estimable. Scale-family classification is empirical within these sizes.

Report observed exact intervals and exact binomial power at both individual one-sided .05 and the discovery two-sided threshold (positive tail). Also increase independent synthetic replicates only for a separate power calculation if needed; primary sample sizes stay fixed. Shuffle middle-bit labels among discordant primary/reference pairs within top-eight-bit bins on the clean view; screen the discovery catalog versus this negative control and repeat one fixed N-bit control on both holdouts. Use an exact randomization diagnostic conditional on each bin's margins for the fixed shuffle sentinel if practical. Low-bit sanity probes use product bits 1,2,3 against each of prime bits 1,2,3, clean matched; report per-split and per-size, Holm over all 216 comparisons.
