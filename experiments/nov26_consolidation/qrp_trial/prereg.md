# Fixed analysis plan for synthetic QR labels
1. Freeze this plan with SHA-256 before generating any modulus, feature, label, or prediction. Deterministic master seed 2026112503. No pilot, optional stopping, or model retuning on held-out data.
2. Generate 8 training and 8 unseen testing moduli per Cartesian cell: 40, 60, 80 exact product bits; (p,q) residues mod 4 of (3,3), (1,3), (1,1). Choose equal-bit-length distinct odd primes by rejection from the appropriate progressions. Disallow prime reuse across moduli. The experiment is balanced across these strata; it is not the natural RSA key distribution.
3. For each modulus sample 192 fresh uniform units per class (++ and --) by rejection of independent uniform representatives, with Euler's criterion only in the labeling routine. Randomize row order. Give final global predictors only public inputs and derived public features. Reserve an additional 96/class independent calibration examples for each test modulus solely for a within-modulus sign/threshold fit.
4. Features fixed by family: normalized sizes/bits of canonical x and N, Jacobi/Legendre values for x and N at odd primes up to 47 and their products, small auxiliary true quartic character components for primes 1 mod 4 up to 47, obtainable with known small-prime arithmetic; public exponentiation probes at N. Bounded simple continued fraction prefixes (8 partial quotients beyond the integer part) for sqrt(x) and sqrt(xN), normalized x mod small prime squares, divisibility and trial valuation features for |x+kN|, k=-2,-1,0,1,2, at primes <=31; local Gaussian/Eisenstein inert-prime norm obstructions (valuations at those small primes). Never compute a power character at N using hidden prime factors.
5. Four prespecified predictors: standardized ridge logistic regression (C=0.1, max_iter=250); ExtraTrees (64 trees, max depth 12, minimum leaf 12, sqrt features); best oriented public threshold stump (selected by training balanced accuracy over features and training quintile thresholds); same stump recipe calibrated anew per individual held-out modulus using only its independent calibration set. Predict once per held-out example. No tuning or selecting good moduli.
6. Endpoint for each predictor: equal-weight mean of the 72 held-out modulus accuracies; stratified modulus-level SE (sample variance within each of 9 equal-weight cells). Use a two-sided t interval with conservative df=7, and Holm-adjust the four two-sided p-values. Give a pointwise 95% CI and familywise decision at 0.05. Approximate power from observed SE by normal 80% power with Bonferroni's two-sided alpha=.0125. This does not bound all bounded features or asymptotic advantages.
7. Separate planted-control run: append a synthetic Bernoulli feature equal to the label independently with probability .55; retrain global stump including this feature and evaluate on held-out rows. Verify it chooses the planted feature. No synthetic feature in clean predictors. Report control with its own pointwise cluster interval.
8. Report full script, plan hash, results, held-out sample size, performance/uncertainty; no unregistered follow-up comparisons substituted for endpoints. Runtime/library versions and run prerequisites recorded.
